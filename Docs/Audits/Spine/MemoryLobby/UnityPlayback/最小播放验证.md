- Test 已有 CH0069 导入副本。原始 skel、atlas 和 4 页 PNG 与工作区资源逐字节一致，6 个文件的 SHA-256 已记录在 `unity_playback_audit.json`。

## 发现的问题与边界

Test 的现有材质 `_StraightAlphaInput=0`，现有 PNG 导入配置为 sRGB=false、AlphaIsTransparency=false，而工程处于 Linear 色彩空间。进入播放前，控制台已有 Spine 材质配置警告。本次通过临时 sRGB 纹理和 straight alpha 材质完成验证，**没有将修正写回 Test 的持久资产**。正式接入时需要明确设置纹理和材质工作流。

进入播放前还读到旧的 API 弃用、缺失脚本和 Unity 服务连接记录；它们不能归为本次 CH0069 播放失败。本次没有手动清空控制台；测试结束前 Error/Warning 查询为空。MCP rendering/stats 曾返回零绘制计数，本报告不使用该资源声称性能达标。

未测 Talk、Pat、Look、Thinking、情绪映射、触摸、TTS 同步和打断；未测 Windows Player Build、长期资源占用或 GiftCompanion 6000.6.4f1。
