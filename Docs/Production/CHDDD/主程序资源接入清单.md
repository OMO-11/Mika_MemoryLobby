| 第 39 节：工具状态动画 | LLM 等待 → Thinking；执行工具 → Working；成功 → Success；失败 → Confused；结果演出结束 → Idle |

## 4. 对外逻辑动作表

时长是片段本体长度，不包括混合；循环动作退出由宿主事件触发。详细 Clip 与实际帧范围在 JSON 清单中。

| 逻辑动作 | 秒 | 类型 / 强度 | 触发 | 结束 |
| --- | ---: | --- | --- | --- |
| Idle | 4.000 | 循环，日常低 | 默认 / 无其他状态 | 新事件切换 |
| Walk | 1.333 | 循环，日常低 | 宿主启动移动 | 移动完成切回当前基础状态 |
| Thinking | 4.800 | 循环，日常低 | 等待 LLM / 解析意图 | 结果或取消后切换 |
| Working | 3.600 | 循环，日常低 | 工具执行中 | 成功 / 失败 / 取消后切换 |
| HeadPat | 4.600 | 循环，情绪中 | 头部长按成立 | 释放 → Exit；拖动可抢占 |
| Dragging | 11.233 | 循环，情绪中 | 真实拖动开始 | 释放 → Exit |
| Sleep | 6.000 | 循环，日常低 | 宿主进入休息状态 | 唤醒 → Exit |
| Wave | 3.600 | 单次，特殊高 | 低频问候 / 欢迎回来 | 自动 Idle |
| Success | 3.400 | 单次，情绪中高 | 工具成功 / 夸奖等明确事件 | 自动 Idle |
| Confused | 3.400 | 单次，情绪中高 | 工具失败 / 疑惑回应 | 自动 Idle |
| HeadClick | 1.800 | 单次，特殊短促 | 头部短点击 | 自动 Idle |
| BodyClick | 2.600 | 单次，情绪中高 | 身体点击 | 自动 Idle |

用户所称 `succeed` 统一映射为 **Success**，`wave/headclick/bodyclick/confused` 等小写名称由适配器归一化；底层当前匹配区分大小写。不要把用户别名直接传给 `PlayAction`，否则可能回退 Idle。

6 个内部短片：HeadPat Enter 0.9 秒 / Exit 1.1 秒，Dragging Enter 0.7 秒 / Exit 0.9 秒，Sleep Enter 2.2 秒 / Exit 1.8 秒。业务调用逻辑动作即可，不能在每帧重复启动 Enter。

## 5. 现有 Unity 控制器接口

以下是**角色适配器内部**调用示例。业务和 LLM 只使用逻辑 ID；示例中的 ID 应从 Manifest / 事件映射解析得到。

```csharp
// 对已导入的 V7 Prefab 调用；所有 ID、混合时长均由映射决定。
bool started = body.PlayAction(resolvedActionId);
body.ReturnToIdle();                    // 有退出短片时先播放退出
body.SetManualEmotion(resolvedEmotion, 0.5f);
body.ResumeActionExpressions(0.28f);
```

- `CHDDDBodyControllerV2`：`PlayAction(string, float seconds = -1)`、`ReturnToIdle()`、`SetManualEmotion(string, float seconds = .5f)`、`ResumeActionExpressions(float seconds = .28f)`；`CurrentAction` 返回逻辑动作，进入 / 退出期间同样返回所属逻辑动作。
- `CHDDDActionFaceControllerV2`：默认随身体状态采样专属眼睑、眉形和嘴型；`BeginTransition(seconds)` 支持续接当前脸部结果；`Advance(deltaSeconds)` 供自定义时钟使用。正常启用组件时无需再次手动调用 `Advance`。
- `CHDDDExpressionController`：静态基础情绪和连续嘴型混合；`SetEmotion` 默认 0.5 秒，`SetEmotionImmediate` 立即定格。V2 使用 `body.SetManualEmotion` 切换脸部控制权，避免两套脚本同时写入。

`PlayAction` 会自动选择 Enter；单次片段的 `nextAction` 已在生成的 Animator 中配置。**当前控制器不会在运行时根据修改后的 JSON 重建 Animator 转换。** 修改流转关系后需同步 Controller。结束摸头、拖动和睡眠时只调用一次 `ReturnToIdle`，等待 Exit 完成，不要按帧调用。

普通切换默认 0.28 秒；Wave / Success 0.18 秒、HeadClick 0.10 秒、BodyClick 0.12 秒；实际值取动作映射。`ReturnToIdle` 进入专用 Exit 时当前实现使用 0.15 秒混合。V2 关闭 Root Motion，Walk 不移动窗口；Dragging 不实现 Win32 拖拽，位置控制属于宿主。

基础手动表情模式不会因下次 `PlayAction` 自动恢复专属脸部：宿主结束手动接管时需要调用 `ResumeActionExpressions`。特殊演出默认保留其独立表情过程，不把模板 Happy / Surprised 每帧压回去。

## 6. 触发、打断和回退

宿主通过状态变化启动动作，维护输入 / 任务取消和演出控制权。资源包不会监听 LLM、工具、鼠标，也不会自行安排随机待机或特殊演出。

- **宪法明确规定**：Dragging 优先于 HeadPat；缺少动作回退 Idle；未知情绪回退 neutral；不能因表现资源缺失中断对话或工具结果。
- **接入建议，尚未实现**：拖动最高，直接触摸次之，工具状态与结果再次之，主动问候和待机最低。拖动发生后取消未完成的长按判定，释放时不补触发 HeadClick。
- **接入建议，尚未实现**：将重复工具结果合并成一次反馈；点击演出中不无限排队；欢迎回来每次实际返回最多一次。特殊演出不按固定短间隔反复播放。
- 物理交互释放走对应 Exit；新高优先级事件允许从当前姿态混合切入，不必先强制 Neutral。事件完成后恢复“仍有效的”宿主状态；若此时工具仍在执行，短反馈结束后宿主需恢复 Working，因为当前单次片段的固定收尾是 Idle。
- 低能量 / Sleep 由主程序状态决定，不在资源中另建一套记忆或精力系统。切换模式时按主宪法取消旧任务并保存 CharacterState。
- 当前底层不提供通用完成事件、任务优先级或取消令牌调度。宿主需结合实际 Animator 状态 / 归一化时间判断结束；不能仅按名义时长写死所有含 Enter / Exit 的等待。

不要将新特殊表情写成 `CharacterEmotion` 字符串。建议在角色本地使用 `Squeeze` / `Omega` 表情演出 ID；接入前能力开关保持关闭，回退到既有 happy / sleepy 或当前标准情绪。LLM 可用动作列表应由实际已接入能力生成，不把未接入的表情、内部 Enter / Exit 或原战斗动画暴露出去。
