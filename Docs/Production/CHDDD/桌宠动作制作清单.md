手册明确列出 Idle / Walk 以及 HeadPat、Wave、Thinking、Working、Success、Confused、Dragging、Sleep。手册没有规定各动作秒数，也没有要求把所有动作设为循环。下列时长、表现、进入退出短片和武器方案均为待确认的制作建议。

## 七种循环

| 动作 | 触发或用途 | 建议循环长度 | 身体表现 |
| --- | --- | --- | --- |
| Idle | 默认待机、任务或互动结束后 | 4 秒 | 自然站姿，轻呼吸、微小重心变化，脚不漂移 |
| Walk | 移动表现 | 约 1.33 秒 | 优先保留原 Café 行走节奏；原地行走，位置由运行时控制，动画不推动窗口或根节点 |
| Thinking | LLM parsing / 等待结果 | 3 秒 | 轻托下巴、细微思考姿态；叠加已验收 Neutral / Concern / Happy 表情 |
| Working | Tool executing | 2.4 秒 | 专注站姿，轻微前倾与小幅规律手部动作，不额外依赖键盘或桌子道具 |
| HeadPat | 持续摸头 | 3 秒 | 被摸头时轻低头，肩部放松，身体轻微摇摆；释放后退出 |
| Dragging | 拖动期间 | 1.6 秒 | 小幅失衡和四肢晃动；由窗口处理移动，拖动优先于摸头 |
| Sleep | 进入睡眠状态 | 5 秒 | 原地打盹、低头慢呼吸；唤醒后退出。Sleepy 仅作为配套表情，不能代替身体动作 |

## 五种短反馈

| 动作 | 触发或用途 | 建议长度 | 身体表现 |
| --- | --- | --- | --- |
| Wave | 问候或主动动作 | 2 秒 | 抬手挥动，回到可衔接 Idle 的姿态 |
| Success | Tool success | 1.8 秒 | 克制的点头或小庆祝，结束回 Idle |
| Confused | Tool failure / API 错误反馈 | 2 秒 | 歪头、轻摊手，结束回 Idle；可叠加 Concern 或 Confused 表情 |
| HeadClick | 头部短点击 | 0.8 秒 | 小幅缩颈或抬头回应，不触发持续摸头循环 |
| BodyClick | 身体点击反馈 | 0.8 秒 | 小幅身体反应；属于 Head/Body 触摸支持的制作补充 |

头部短点击反馈有手册依据；BodyClick 的单独 Clip 名称和具体表现为补充建议，手册只规定 Body 触摸支持，没有指定该动作名称。

## 六个进入／退出短片

- HeadPat_Enter / HeadPat_Exit：普通站姿与摸头循环衔接。
- Dragging_Enter / Dragging_Exit：拿起、放下时与拖动循环衔接。
- Sleep_Enter / Sleep_Exit：打盹和唤醒，与睡眠循环衔接。

长度建议 0.4–1.2 秒，以姿态衔接为准。总计建议 18 个身体 Clip：7 个循环、5 个短反馈、6 个进入／退出。若原始 Idle / Walk 经过实际预览、修整后可复用，允许以原动画为基础，不仅凭名称认定合格。

## 制作与验收规则

- 保留 Generic Rig、原骨骼名称与层级、特殊骨骼、光环绑定；固定 30 FPS。
- 原始 CH0069 保持不变；在 Material/CHDDD 制作副本中保存新 Action。
- 已人工验收的眼睑、眉形、嘴型、材质和表情过渡保持其数据；身体动作独立制作。
- Base 播放身体动作，Emotion 叠加表情，Procedural Rig 仅处理 LookAt 与小幅动态修正。
- 接入时处理身体头部运动、表情轻微头倾和 LookAt 的覆盖关系，避免面部层抹掉动作中的头部运动。
- 循环检查首尾姿态、速度和多次连续播放；单次动作和进入／退出短片不设循环。
- 手册未给定身体切换时长；初始建议普通状态切换 0.2–0.4 秒，较大姿态改变使用对应短片。
- 检查脚底滑动、手臂穿身、头发／裙摆／披肩变形、光环跟随与透明窗口中的角色边界。
- 骨骼过渡与已验收表情过渡分别配置；不把表情保持 Clip 当成全身动作。
- 动作、循环标记、触发映射与优先级写入 Manifest；缺失动作回退 Idle。
- 优先级建议 Dragging > HeadPat／点击 > 工具状态 > Idle；只有 Dragging 高于 HeadPat 是手册明确规定，其余为制作与运行时建议。
- 检查 Unity 导入、Generic Avatar、Clip 循环配置与运行时切换；动画不启用自动根位移。

## 建议制作顺序与待确认选择

先固定 Idle 基准姿态，再制作 Thinking / Working、互动循环、Sleep / Walk，最后补齐短反馈与进入／退出；每批交付预览供人工检查。

建议暂时隐藏持枪附件，使用自然站姿和轻幅度桌宠动作；武器资源与原始动画保留。Sleep 首版采用原地打盹。待确认：是否接受上述 18 个 Clip 范围与武器／睡姿方案。

| CH0069_Cafe_Idle | 4 秒 | 抽样为放松站姿和轻微身体变化，优先作为 Idle 基础；保留节奏，分离原面部通道 |
| CH0069_Cafe_Walk | 1.333 秒 | 抽样为日常步行，优先作为 Walk 基础；制作时再检查脚底接触、根位移和与 Idle 衔接 |
