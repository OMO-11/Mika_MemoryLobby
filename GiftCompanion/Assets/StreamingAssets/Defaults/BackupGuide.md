# 备份与迁移说明

从Home选择“资料与连接”。陪伴空间的设置、桌宠的桌面设置也能进入此页。

联网配置：输入自己的DeepSeek API Key，点击“保存并重新启动”。“测试连接”会产生一次短请求，保存本身不发请求。Key只在当前Windows账户加密保存。没有Key也能进入场景、查看已有资料；联网对话需要配置后再用。

备份：选择是否包含历史语音，点击“备份资料”，选择一个新的文件名。默认精简备份保留对话、记忆、人物卡、歌单/空间清单、导入素材、参考音频和日记MD；未包含的历史音频不会在恢复后偷偷重新合成。备份中不包含Key、模型运行环境、日志或开发测试资料。请将备份放到另一个可靠位置；它含有你的私人对话，不要当作诊断文件分享。

恢复：点击“从备份恢复”，阅读时间与范围预览，再点击“确认替换当前资料并重启”。程序先保存一份当前资料备份到资料目录Backups，关闭数据库后再恢复。中途故障会回滚；原始目录另保存在RestorePoints。不要手动混合不同快照里的memory.db、WAL和配置。

恢复会回到备份时刻，包括当时的遗忘与排除状态。现在遗忘一条记录，不会删除以前备份里的副本。请自行决定保留或删除旧备份。日记MD中的手工批注会作为文件保留，不会反向改写数据库。

换电脑：复制完整程序目录，再从备份恢复资料。重新输入Key、重新登记应用和搜索目录，并重新启用需要的桌面工具。恢复不会执行历史桌面操作。单独复制EXE或Windows密钥密文不能迁移全部资料。

排错：“资料检查”可重新载入语音配置、导出脱敏诊断，以及选择某一个配置文件恢复默认。重置前再次点击确认，原文件移到ConfigRecovery，其他配置不动。修改外部文件后，点击“重新读取资料（重启）”统一加载，避免一半组件还使用旧内容。原人物卡在Config/character_card.json，BGM清单在Config/bgm_playlist.json，空间清单在Config/companion_spaces.json。

资料文件夹中的Config、Content、VoiceReferences、Diary和memory.db属于玩家。Secrets是本机密钥；RuntimeCache是可重新创建的推理缓存；AudioCache含历史复听音频，删除会失去对应复听能力。请在应用内管理缓存。Logs/Diagnostics是维护输出。Backups/RestorePoints不会被自动套入下一次备份。

首版备份上限为单个文件2GiB、全部资料32GiB、3万个文件；只接受约定的数据文件类型和正常目录，不跟随符号链接。若你手动加入其他类型导致备份提示，请保留原件并单独归档。旧程序会拒绝高版本数据库，请使用配套程序和快照回退。更新采用完整的新版本目录，保留原资料目录并先备份。
