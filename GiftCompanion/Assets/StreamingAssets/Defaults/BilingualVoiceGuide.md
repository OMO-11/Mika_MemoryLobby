# 中文文字与双语声音

进入陪伴空间后，按 Esc → 设置 → 声音与复听。点击“朗读：中文 / 日语”切换，再点击“保存声音设置”。初始仍为中文，不会自动更改你的选择。

切换会停止当前回复并重新准备音色，本机验证约二十至四十多秒，首次加载可能更慢。准备期间可以继续文字聊天；声音准备好后用于新的回复。音量滑块控制角色声音，BGM 音量独立。

你始终用中文聊天：主模型的中文回复先显示并写入聊天记录。选日语时，后台单独把中文回复分句本地化成日语，再交给已提供的日语克隆模型。中文模式跳过翻译。中文不会直接送给日语音色，译文也不会覆盖人物记忆或中文原文。字幕在开始播放时对应所朗读段落的中文。

日语本地化复用已配置的 DeepSeek Key，产生少量额外 API 用量。采用独立的 Flash 非思考调用，每次只传当前中文短句，不传整段聊天、人物记忆或日记；没有本地翻译大模型。断网、翻译失败时保留中文文字，不会偷偷改用另一种声音。可切回中文或稍后重试。

MomoTalk 中“中文复听 / 日语复听”标明当时的语言。切换只影响后续回复；已经保存的声音保持原语言，复听无需联网、无需模型。不存在的音频不补生成。

## 文件位置

菜单“我的资料”可打开资料目录。正常运行资料在 `%LOCALAPPDATA%\GiftCompanion`，编辑器资料在工程 `UserData`。

- `Config/settings.json`：`VoiceLanguage` 为 `zh` 或 `ja`，及 `VoiceEnabled`、`VoiceVolume`。普通玩家直接用菜单修改即可。
- `Config/voice_runtime.json`：端口、队列、分句与音量压低参数。`Profile` / `InferenceConfig` 是旧版兼容字段；实际音色由上面的语言选择匹配现有中日配置。
- `Config/speech_localization.json`：独立翻译模型名、超时、输出限制、短句缓存上限、日语本地化说明。无 Key。修改后重启应用生效；错误文件保留，不影响中文聊天。不要填入任意 API 地址。
- 安装目录 `Runtime/GPT-SoVITS/voice.json`、`voice-ja.json` 及对应 YAML：分别引用已有中日模型、参考音频。两种语言共用同一运行环境，每次只加载一种音色。请保留原始资源。
- `AudioCache/<随机目录>/0000.wav`：每段音频；旁边的 `0000.speech.json` 可用记事本查看中文、实际朗读内容、语言、音色指纹及翻译来源。这些是缓存，可通过菜单一起清理；不属于聊天或记忆事实。
- `memory.db`：保留 v9 结构，原中文聊天与旧语音索引继续可用；此次无需升级数据库。

可先用相同中文话题分别在两种语言下聊天，再比较相似度、音量、停顿、语气和等待时间。声音相似度与日语措辞仍以你的实际试听反馈为准。
