# 表达与日记

默认继续日语，输入与历史继续中文。声音就绪时，字幕随实际语音出现，保留现有句间呼吸与停止操作。

活泼、害羞仍使用原先的参考。此次增加恼火、伤心、犹豫、平直朗读的表达目标：恼火克制一些、伤心较慢、犹豫借用害羞参考和迟疑措辞，平直朗读减少演绎、保持正常速度。它们只是现有模型的表达近似，没有新训练的怒声/哭腔，也无法保证音高完全不变。可以自然聊天，或明确说“这句请平静一点 / 有点犹豫地说”。

新日记会按话题、相处变化分成自然段，段间留空行。模型仍给超长段时，程序仅补空行，不改写文字，不另花一次API调用。完整正文先写入数据库，再输出同样内容的Markdown。

颜文字默认允许每篇最多4个，短篇少放、长篇可多些，不强制凑满、不每段必放；严肃内容可以不用。原版最多1个的旧策略在下次主动生成时放宽，你明确关闭颜文字或设置过其他上限会保留。已有日记不自动改写；再次点击生成可按新规则写一份新回顾。

资料目录中：

- `Config/voice_delivery.json`：表达目标、参考音频和语速。`ja-annoyed / ja-sad / ja-hesitant / ja-flat` 是此次新增的配对。
- `Config/speech_localization.json`：v3规则，保持原意，用相应语气本地化成日语；旧的原始规则升级，自定义规则保留。
- `Config/diary_policy.json`：`MaximumKaomoji=4`（可0–12）、`PreferredParagraphCharacters=160`、`MaximumParagraphCharacters=260`。上限越大不代表模型必须用满。修改后下次主动生成生效。
- `AudioCache/` 中的 `.speech.json`：`Emotion` 是原共享心情，`VoiceIntent` 是实际发声目标，二者可以不同；真实使用的参考和语速同样可查。

发声目标只影响表现，不会另造一份角色或记忆。全部复用现有模型与参考，未增加本地大模型。更完整的学习说明见工程 Docs/expression_diary_implementation.md。
