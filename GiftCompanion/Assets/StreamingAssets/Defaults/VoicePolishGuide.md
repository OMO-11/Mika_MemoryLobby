# 语音与日记微调

默认使用日语音色。仍然输入中文，主模型生成中文；日语经过独立、低成本的常体本地化后朗读。按 Esc → 设置 → 声音与复听，可选中文、开关语音和调整音量。

开启并就绪的语音模式中，角色先思考，实际发声时才显示对应句子的中文；不会先闪现整段再重播。无语音、准备中或生成失败时继续文字聊天。MomoTalk 保留完整中文记录。

句间默认额外留0.45秒呼吸，短分句0.18秒。生成下一段时已经等过的时间也算停顿，不重复等待；停止和发新消息立即打断。复听采用同样的节奏，BGM 在句间保持柔和，不反复忽大忽小。

本次使用你提供的中日参考素材：日语明朗与害羞参考分开，中文换较柔和参考；情绪同时提供给本地化和参考选择。原模型权重没变，语速作小幅调整，没有用播放器变调代替情绪。素材覆盖有限，关切、低落等仍用原参考加较慢语速；效果请以实际试听为准。

新版本第一次读取旧声音设置时把默认语言调为日语，保留原音量/开关；之后你主动选择中文并保存，重启会保留你的选择。

## 文件

通过菜单“资料与回顾”可打开资料目录：

- `Config/settings.json`：`VoiceLanguage` 为 ja / zh；`VoicePreferencesVersion=2` 标记已应用本次默认更新。
- `Config/voice_runtime.json`：`SentencePauseSeconds=0.45` 与 `ClausePauseSeconds=0.18`，重试语音或重启后生效。
- `Config/speech_localization.json`：本地化说明使用亲近、活泼的常体，减少敬语；旧版原始规则自动升级并留备份，你自己修改过的规则保持。改后重启。
- `Config/voice_delivery.json`：语言、情绪、参考音频、准确转写、语速的配对。`VoiceReferences/` 是数秒的WAV，不是新的模型。改后重试语音或重启。新增参考必须3–10秒并与转写一致，不要填任意系统路径。
- `AudioCache/` 每段 `.speech.json` 增加情绪、实际参考ID和语速，可用记事本核对。缓存仍可离线复听；旧音频不会因改规则而自动重做。
- `Config/diary_policy.json`：`MaximumKaomoji=1` 表示每篇最多一个短颜文字，可设0（不用）或2；严肃内容不强加。只在你主动生成新回顾时应用，旧MD不改。日记仍然是对已保留聊天的回望，不增加记忆事实。

所有配置错误文件保留。高级字段不熟悉时可以保持原值，把你的听感交给维护者调整。日语仍需联网翻译；声音和日记的主观效果等待你的体验反馈。
