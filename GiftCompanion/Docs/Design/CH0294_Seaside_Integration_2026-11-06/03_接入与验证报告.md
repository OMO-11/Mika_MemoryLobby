# 海边记忆大厅接入报告

日期：2026-11-06。

## 本次实现

按用户最后指示，复用已有陪伴空间接口接入 CH0294，菜单仅作过渡占位。未采用初稿中的独立精细玻璃面板，也未增加海边菜单运镜。

- 原大厅默认保留，Esc → 陪伴空间 → 海边记忆大厅 → 进入。Esc 逐层退回人物；海边再次 Esc 直接开关简易菜单。
- 沿用现有六项菜单与业务页面。背景使用实时降采样模糊和半透明冷色覆盖，文字保持清晰；菜单下移避开左上曲名。人物、海面和星空在菜单后继续运行。
- 原始六个骨架/图集/贴图文件逐个 SHA-256 与交付包一致。保留已有单一世界渲染加载器，局部适配原交付资源的固定纵向视野、背景延展与海面垫底；不复制其 URP、Linear 全局设置或第二套 Spine runtime。
- 保留 1.25 倍入场与关键帧白光衔接，Enter 可结束入场后输入，减少动态效果跳过入场。接入额头抚摸、松开收尾及三类轻微待机表情。
- 任意合成语音沿用实际 PCM 能量驱动口型，分段播放器将能量传给海边角色，暂停或停止后闭嘴。不把原生固定剧情对话当作任意 TTS 口型，不播放缺失的游戏语音。
- 旧空间配置按 ID 增补海边条目，保留玩家选择与已有导入空间；原文件写入前保留上一版。不会因新版本默认清单而重置玩家清单。
- 切换沿用原事务：准备、校验与选择保存成功后更换画面，收尾旧对话/复听及旧资源；仍共享同一 CharacterCore、数据库、人物卡与记忆。

原大厅的窗边运镜、细纱/星空/流星和既有维护入口继续保留。海边初次进入可看到原生入场，不需要等待入场结束才能按 Esc。
