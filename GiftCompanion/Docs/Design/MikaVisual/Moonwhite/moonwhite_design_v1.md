## 0. 结论先行

这版不沿用 V2 的“暖白信笺铺在画面上”的思路，而是换一套空间逻辑：

**夜玻璃负责交互，月白纸负责阅读；角色负责沉浸，界面只负责退后。**

- **概念名**：月白夜蓝 / Moonwhite Nocturne
- **一句话**：让界面像月光一样，停在画面边缘。
- **常态**：70% 以上的画面留给未花和场景，只保留字标、时间、音乐、菜单、首次提示。
- **阅读态**：日记、MomoTalk、人物设定、设置使用“月白纸页”，保证长文阅读；其余交互使用深色“夜玻璃”。
- **未花元素**：只保留四个结构性母题——光环弧、羽翼线、缎带书签、星月细线。不做角色贴纸、不做满屏爱心、不做甜腻的粉色渐变。
- **不动功能**：保留现有信息架构、日记/MomoTalk 约束、语音与输入行为、设置项和退出流程。桌宠不在本轮范围。

## 1. 对现有 V2 的判断

V2 已经解决了“可读、清楚、不遮脸”，这些要继续保留：

- 左侧面板避开右侧面部；
- 暖白纸上的深色正文对比充足；
- 日常只保留少量边缘控件；
- 日记、MomoTalk、设置都有明确的信息层级。

但作为一次“全新设计”，V2 仍有四个可以明显往前走的地方：

1. **界面语言还是“应用卡片”**：左上圆形标记、右上深色时间卡、底部胶囊提示、右下矩形菜单，四件套都在提醒“这是软件”。新方向要把它们收成更轻的“电影 HUD”。
2. **暖米白与冷蓝画面对冲**：V2 的纸张偏暖、偏厚，像把信纸放在画面之上；新方向只在真正阅读时出现纸页，而且纸色改为更中性的“月白”，让它像被月光照亮，而不是另一套黄色 UI。
3. **所有界面都像同一块面板换内容**：菜单、日记、设置都是左侧浅色大板，缺少节奏。新方向用两种材质建立节奏：**交互是夜玻璃，阅读是月白纸**。
4. **未花元素主要集中在颜色和圆角**：粉色、金色、星月图标都有，但还没有形成结构。新方向让光环成为品牌标记，羽翼成为选中线，缎带成为书签，星月只做 1px 细线，不靠堆装饰。

新方向不是把 V2 调暗或换色，而是重新划分画面：**常态更空，对话更像字幕，菜单更像夜间索引，阅读更像一页被月光照亮的纸。**

## 2. 设计原则

### 2.1 角色优先

- 1280 × 720 下，面部安全区约在 `x 56%—82%`、`y 28%—72%`。这只是 CH0069 的安全区，不能写成所有空间的通用坐标。
- 常态不放大面板；菜单从左侧展开，阅读页控制在左侧 660px 内；对话只占底部约 170px。
- 打开阅读页时，场景只做轻微压暗，不模糊整张画；右侧面部继续可见，提醒“她还在那里”。

### 2.2 两种材质

| 材质 | 用途 | 表现 |
|---|---|---|
| 夜玻璃 Night Glass | 菜单、音乐、空间、对话字幕、输入、悬浮提示 | 深夜蓝、92%—96% 不透明、1px 冷白细边、极轻阴影；不依赖毛玻璃也能读 |
| 月白纸 Moon Vellum | 日记、MomoTalk、人物设定、设置 | 中性月白、细白边、2%—3% 纸纹、深墨正文；像被月光照亮的一页，而不是厚卡纸 |

规则：**只读长文和表单用纸，操作与氛围用玻璃。** 这样界面不会全亮，也不会全暗；明暗有节奏，长时间看不累。

### 2.3 克制的未花元素

四个母题，整页最多出现两种：

- **光环弧**：只出现在字标上方、入口页标题上方，以及“正在说”的微型状态点；不做满屏光环。
- **羽翼线**：菜单选中项的右侧、人物设定页标题的收笔；一条 1px 曲线即可。
- **缎带书签**：只在日记页右侧边缘出现一小段，12 × 44px；不做蝴蝶结贴纸。
- **星月细线**：图标与分隔线；四角星用于“此刻/选中”，月牙用于音乐与夜间状态。

粉色只承担三件事：未花的名字、选中态、主要动作。金色只做细线和小图标；**金色不承担正文小字**。

### 2.4 低疲劳

- 不使用纯白大面积；月白纸最高亮度控制在 `#F4F1EB` 左右。
- 强调色面积不超过画面 5%；不同时使用高饱和粉、金、蓝三色互相争抢。
- 常态不播放循环粒子、呼吸光晕或全屏渐变；角色的 Spine 动效已经提供生命感。
- 动效只做 120—220ms 的反馈；不阻塞输入。
- 大段正文 30—36 字/行，行高 1.9 左右；不用手写体做正文。

### 2.5 文案分工

- **系统文案**：短、具体、可预期。用“你”，不用“主人/亲爱的”。
- **未花台词**：可以温柔、有一点俏皮，但不默认恋爱关系、不虚构共同经历、不做独占承诺。
- **高风险操作**：退出、删除、恢复、覆盖必须朴素明确，不包装成撒娇或剧情选项。
- 不在界面里写“好感度”“羁绊等级”“在一起第 N 天”等未经确认的关系计算。

## 3. 色彩系统：月白与夜蓝

从画面取色后，UI 不额外引入高饱和色，只把画面里的夜蓝、雾蓝、粉发、月光金整理成可用的层级。

| 角色 | 建议色值 | 用法 |
|---|---|---|
| 夜蓝 900 | `#080F1E` | 最深背景、模态遮罩 |
| 夜蓝 800 | `#0D1830` | 夜玻璃基色 |
| 夜蓝 700 | `#16233F` | 夜玻璃悬停 |
| 月白 | `#F4F1EB` | 纸页、深色上的主文字 |
| 月白高光 | `#F7F3EC` | 纸页顶部高光、标题 |
| 雾灰 | `#C9C4D0` | 深色上的次级文字 |
| 夜灰 | `#9893A6` | 深色上的说明文字 |
| 未花粉 | `#E9B9C9` | 名字、选中、主要动作、语音状态 |
| 深玫瑰 | `#8E4560` | 纸页上的强调文字、主按钮 |
| 星金 | `#D6BC86` | 深色上的细线与星月图标 |
| 纸金 | `#A78A5A` | 纸页上的细线、书签边；不用于正文 |
| 雾蓝 | `#AFC4F0` | 冷光、教师消息、极少量信息状态 |
| 危险 | `#8F3F4A` / `#E6A3AA` | 纸页/深色上的危险文字，不做整块红按钮 |

已计算的对比度（用于方案校验，最终以 Unity 实际合成背景为准）：

- 月白 `#F5F1EA` on 夜蓝 `#0D1830`：**15.67:1**
- 雾灰 `#C9C4D0` on 夜蓝：**10.32:1**
- 夜灰 `#9893A6` on 夜蓝：**5.93:1**
- 未花粉 `#E9B9C9` on 夜蓝：**10.29:1**
- 深墨 `#242638` on 月白 `#F4F0E9`：**13.12:1**
- 深玫瑰 `#8E4560` on 月白：**5.83:1**
- 深色文字 `#1B2033` on 未花粉：**9.41:1**
- 纸金 `#A78A5A` on 月白：**2.88:1** → 只做线条/装饰，不承担文字
- 星金 `#D6BC86` on 夜蓝：**9.75:1** → 可做小图标，不做长段正文

补充规则：

- 纸页上的正文只用 `#242638`，次级说明用 `#6A6570`（约 5.5:1），不再往浅灰走。
- 深色上的蓝色只做场景统一和教师消息，不把蓝色变成第二个主色。
- 所有“选中”先靠线宽、留白和底色变化表达，再靠颜色；不依赖颜色单一通道。

## 4. 字体与排版

### 4.1 字体组合

- **中文**：继续使用现有 `Noto Sans CJK SC`，不新增整套中文字体。标题靠字号、字距、留白和细线区分，不靠粗黑体。
- **拉丁/数字**：`Georgia`（时间、页码、序号、英文小标）。给界面一点印刷品的气质，同时不抢中文。
- **可选增强**：若后续允许增加一个字重或一套标题字体，建议只补 `Noto Serif CJK SC Medium` 或 `Source Han Serif SC Medium`，仅用于页面大标题与入口页，不用于正文。若不想增加包体，就维持现有 Sans + Georgia 方案（推荐默认）。
- 不用楷体做正文；不用手写体；不用全大写中文。

### 4.2 字号层级（1280 × 720 基准）

| 层级 | 字号/行高 | 说明 |
|---|---|---|
| 入口主标题 | 40—44 / 1.35 | 入口页“老师，欢迎回来。” |
| 页面标题 | 28—30 / 1.4 | 菜单、日记、设置 |
| 面板副标题 | 16—18 / 1.6 | 说明性短句 |
| 正文 | 15 / 1.8 | 设置、菜单描述、一般说明 |
| 阅读正文 | 19 / 1.95 | 日记；可在设置里调字号与行距 |
| 对话字幕 | 22—23 / 1.62 | 画面底部字幕 |
| MomoTalk | 15 / 1.75 | 消息气泡 |
| 说明/元数据 | 9—11 / 1.6 | 英文小标、日期、页码、辅助说明 |
| 时间 | 24—26 / 1 | Georgia 数字 |

字距：

- 中文标题 `0.04em—0.08em`；英文小标 `0.22em—0.28em`；正文不额外拉字距。
- 英文小标只在每页出现一次，作为“页码/分类”的节奏点，不堆满全屏。

### 4.3 行宽与留白

- 8px 基础网格；常用间距 8 / 12 / 16 / 24 / 32。
- 1280 宽：左右安全边 32px；纸页面板内边距 32—36px。
- 日记正文最大宽度 34em，约 30—36 个汉字/行。
- 菜单行高 58—62px，标题与说明之间 4px；菜单整体至少留 32px 的底部呼吸。
- 所有点击目标至少 44 × 44px；视觉尺寸可以更小，但命中区不能小。

## 5. 图片与素材设计

### 5.1 背景画（现有 CH0069）

- 保持原画，不重绘、不叠加角色贴纸、不把 UI 烘进背景。
- 16:9 窗口使用 `object-fit: cover`，焦点偏中右：建议 `object-position: 50% 46%`。4:3 窗口接近完整画面，可改用 `50% 50%`。
- 不使用全屏模糊或大面积黑幕；只在左侧、底部、入口页使用局部渐变遮罩。
- 画面已有的冷窗光在右侧，UI 的暖金只做细线，不与其抢光。
- 现有原图 3460 × 2568，原型可直接引用；正式实现建议导出 1920 × 1080 / 2560 × 1440 的 16:9 裁切版和 1440 × 1080 的 4:3 版，避免每次运行时缩放 3460px 大图。

### 5.2 未来新场景的构图规则

如果后续增加陪伴空间，背景图应按“可承载 UI 的画”来设计，而不是先画完再找地方塞面板：

- 角色面部放在画面右侧 60%—75% 水平区间、35%—52% 垂直区间。
- 左侧 30%—35% 保持低细节、低对比、偏暗，留给菜单/纸页面板。
- 底部 25% 不要放高对比装饰，留给字幕与输入。
- 右上角 18% 不要放细碎高光，留给时间。
- 一个主光源（冷窗光）+ 一个微弱暖光（月/台灯）即可；不要五彩霓虹。
- 色相控制在 60% 冷蓝、30% 月白/雾蓝、10% 粉/金。人物服装与发色可以更亮，但背景装饰要退后。
- 人物与背景最好分层输出：背景干净版 + 角色 Spine；UI 只依赖背景的安全区，不依赖角色帧。
- 2x 输出，保留无 UI 的干净版；不要让旧 UI 留在图里。

### 5.3 UI 图片素材

| 素材 | 设计 | 规格 |
|---|---|---|
| 音乐封面 | 深蓝紫星图：1px 金色轨道、月牙、三颗四角星、底部 8px “MIKA GIFT / 01”。不放第二张角色立绘 | 1:1，建议 1024 × 1024，SVG/PNG |
| 空间缩略图 | 从 CH0069 裁 16:9，保留面部与星窗；不在图上压文字 | 16:9，建议 1600 × 900 |
| MomoTalk 头像 | 28px 光环单色徽记，不裁脸部；若用户提供头像再替换 | SVG，深玫瑰/浅粉两版 |
| 纸纹 | 256 × 256 可平铺的细纸纹，2%—3% 不透明度；不可见重复 | PNG/WebP，单张小于 40KB |
| 图标 | 24px 网格、1.5px 线宽、圆头圆角；星、月、羽、书、聊、音符、窗、调节线 | SVG；Unity 用 2x/4x Sprite |
| 选中羽翼线 | 18—22px 单线羽翼，只出现在当前菜单项右侧 | SVG，1.5px |
| 缎带书签 | 12 × 44px 小书签，右侧边缘，浅粉，底部剪角 | SVG/CSS |
| 分隔线 | 1px 金线/冷白线，长 24—48px，不贯穿整页 | CSS/9-slice |

图片气质：低调、带一点印刷品感；不反光、不厚金边、不做玻璃拟态高光、不做大面积装饰插画。

## 6. 布局：各界面怎么排

### 6.1 陪伴大厅（常态）

```
┌──────────────────────────────────────────────┐
│  ╭─ halo ─╮                       21:06      │
│  Mika                            10月24日 · 六 │
│  记忆大厅 / MEMORY LOBBY                     │
│                                              │
│                 [ 面部安全区 ]                │
│                                              │
│  ♪ 记忆大厅 BGM     Enter 和未花说说话   ◯ 菜单 │
└──────────────────────────────────────────────┘
```

- 左上：光环弧 + `Mika`（Georgia italic，26—28px）+ `记忆大厅 / MEMORY LOBBY`（9px，拉开字距）。不加圆形徽章底。
- 右上：无卡片时间。`21:06` 用 Georgia 24—26px，下一行日期 9—10px；加轻微文字阴影保证压在窗光上也能读。
- 左下：音乐入口为一条“正在播放”行——36px 细边音符圆 + 曲名/循环状态；没有厚底胶囊。
- 右下：44px 圆形菜单按钮，三条细线图标，环上一个小粉点；不使用矩形“菜单”按钮。
- 底部中央：一条低存在感的提示 `Enter 和未花说说话 · Esc 打开菜单`，半透明玻璃底仅用于保证可读；10—12 秒后降到 35% 不透明度。
- 常态不显示任何状态看板、经验值、纪念日、天气或角色数值。

### 6.2 纯欣赏

- 隐藏全部应用控件，只保留场景。
- 点击画面或按 Esc 回到常态；进入后的前 2 秒可显示一次“点击画面返回”，随后消失。
- 不在纯欣赏模式里放循环粒子或额外滤镜。

### 6.3 对话

- 底部一条约 168—180px 的字幕带，左右 32px、底部 24px；不是完整卡片。
- 背景从透明渐变到夜蓝 86%，顶部一条 1px 冷白细线；左侧 2 × 26px 浅粉竖线作为“说话中”标记。
- 姓名 `未花` 15px 粉色、字距 0.14em；一条 32px 金线；右侧三根 6—10px 的静态/缓慢呼吸声纹 + `正在说`。
- 正文 22—23px，最大宽度 820px，最多约 30 个汉字/行；保留角色表情和右眼。
- 操作区在右下：`先看文字` 为幽灵文字按钮，`回应` 为浅粉小胶囊（深色字）。两个都在 44px 命中区内。
- `先看文字` 只影响本轮显示方式；状态变为“文字模式”，不伪造下一轮偏好。

### 6.4 输入

- 夜玻璃输入板：左侧 32px、底部 24px、宽 680px、圆角 18px；不铺满全宽，不挡脸。
- 顶部 `写给未花`（9px 粉/金小标）与 `Enter 发送`；正文透明 textarea，17px/1.8，浅色占位“和未花说点什么……”。
- 底部提示 `Shift+Enter 换行 · Esc 收起`，右侧 `收起` 与 `发送`。
- 保留草稿：收起后再次打开仍在；发送成功后才清空。中文输入法组词期间 Enter 不发送。
- 不使用白色大输入框压在画面上；输入是“在夜色里说话”，不是填表。

### 6.5 等待

- 仍使用底部字幕带，姓名和状态改为 `未花 / 正在想一想`。
- 用一条 140px 的浅粉细线缓慢呼吸，或一个四角星低透明度呼吸；不出现旋转 loading、不出现夸张省略号动画。
- 操作：`先看文字` 与 `停止`。停止后回到输入并保留草稿。

### 6.6 菜单

- 左侧全高抽屉，宽 392px；夜玻璃、右侧 1px 冷白边、外侧柔和阴影。
- 头部：`MIKA GIFT / MENU` 9px；标题 `今晚，想做点什么？` 30px；副句 `不急，慢慢来。` 11px；右上 44px 关闭。
- 两组：
  - `相伴 / TOGETHER`：MomoTalk、相处日记、背景音乐。

|---|---|---|---|---|

## 9. 文案

### 9.1 语气规则

- 系统：清楚、短、不卖萌。例：`保存设置`、`回到大厅`、`添加音乐`。
- 未花：自然、明快、有分寸；可温柔，但不默认恋爱、不独占、不编造经历。
- 每屏最多一句抒情文案；按钮和说明以清楚为先。

## 10. 无障碍与长期使用

- 正文对比度 ≥ 4.5:1；大字号 ≥ 3:1；金色只做线，不承担小字。
- 所有可点击元素 44 × 44px；关闭、返回、发送、停止必须可键盘到达。
- 焦点环：深色上用 `#F0C8D5` 2px + 2px 偏移；纸页上用 `#8E4560`。
- 支持 `prefers-reduced-motion`；减少动效时面板直接出现，声纹静止。
- 中文输入法组词期间 Enter 不发送；Esc 收起输入但保留草稿。
- 日记大字号/行距可调；长文页脚固定，不因字号变大而消失。
- 滚动条细、低对比，不抢视觉；面板内容可以键盘滚动。
- 危险操作只用文字和细边，不做大红块；确认里写清对象、影响和取消方式。
- 面板外点击/ESC 收起；收起后焦点回到触发按钮（正式实现）。
