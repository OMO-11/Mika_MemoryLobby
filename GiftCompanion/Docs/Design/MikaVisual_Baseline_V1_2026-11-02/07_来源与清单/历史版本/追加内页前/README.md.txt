**先双击“开始阅读.html”。** 可以直接看GIF、关键帧、详细报告和交互预览，不需要启动Unity或配置服务。

- [Markdown报告](设计介绍报告.md)：便于长期维护和代码审计。
- [交互预览](01_确认效果/preview.html)：点人物后方的时间前往窗边，点“回到未花”返回；其余菜单为布局示意。

01是效果，02是实际场景与分层，03是萝莉体，04是图标和规则，05是代码参考，06是验证证据，07是清单。所有预览依赖的图层和萝莉体都在本目录内，可整体复制后打开。

大体积BGM留在原工程并记录来源，不重复复制；此预览不播放音频。密钥、用户数据、语音模型和发布包不在本档中。当前定稿是视觉参考，正式Unity程序尚未改版。

后续精修另建版本，不覆盖这份基准。代码审计可阅读05_实现参考及文件SHA清单；维护者可运行其中的verify_archive.py做只读校验，不建议在本基准内直接重新渲染。
