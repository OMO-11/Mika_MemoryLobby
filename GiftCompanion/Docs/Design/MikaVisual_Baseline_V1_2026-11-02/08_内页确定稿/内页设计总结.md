# 窗边内页设计总结与确认记录

2026-11-02，Asia/Shanghai。玩家反馈“整体做的不错，日记选择浮字版本的”，据此将本轮整体方向和浮字日记归入第一版视觉素材。

## 1. 本轮确定了什么

设置、聊天记录、人物设定和陪伴空间沿用当前初稿方向；日记明确选择窗景浮字版。文字直接融入已确认的窗边场景，保留夜空、月光、纱帘与右上时间日期。左侧导航高亮当前页，不增加毛玻璃椭圆或厚重独立面板。

萝莉体继续用于导航、标题、正文和字段；暖白正文、细线分隔与透明控件保持一致。第一版主场景取景、运镜、时间菜单位置和原始素材不因内页归档而改动。

## 2. 各页布局

| 页面 | 已确认的初版方向 |
|---|---|
| 设置 | 声音、画面与阅读、资料三组文字页签；细线滑杆和语言选择，保存/恢复入口清楚 |
| 日记 | 纯窗景浮字，无正文底板；自然段、舒适行距、滚动和继续阅读 |
| 聊天记录 | 纵向消息，称呼和时间分层，语音复听按钮靠近角色消息 |
| 人物设定 | 名称、称呼、关系基调、说话方式分组，用下划线字段与保存/取回操作 |
| 陪伴空间 | 当前空间小预览、名称和简洁添加/清单入口，不铺满大卡片 |

## 3. 日记的最终选择

采用浮字版，薄信笺版未采用。归档预览的日记导航默认且只进入浮字页；即使手动使用旧的diary-paper哈希，也会转到浮字日记。正文底板样式已从采用稿CSS去除，备选图片另放“备选对照_未采用”。

日记仍是玩家手动决定是否生成的全程记忆总结，用“回望至今”表达从开始相伴至现在的范围。界面没有改回自动生成或只总结当天。示例正文保持分段和适量颜文字；它不是实际生成的记忆，不陈述真实共同经历或关系变化。

正文20逻辑像素、行高1.78，内容区267像素高；可滚动并有“继续阅读”入口，底部柔和裁边提示后面还有文字。标题、日期和操作保持克制，不额外增加关系分数或新的记忆机制。

## 4. 归档内容与分类

08_内页确定稿保存五页采用稿、设置两个补充子页、可点击预览、HTML/CSS/JS、独立page_design.json、示例正文及本总结。页面图片按中文名称保存；薄信笺与旧A/B对照移入未采用子目录。预览只引用本总归档的图层和萝莉体，因此整个归档文件夹可独立复制后打开。

原草稿目录原位保留，不把历史对照改写成已选稿。追加前的资源清单、校验结果和阅读文档已备份到07_来源与清单/历史版本/追加内页前。总入口、设计总报告和资源哈希清单随本次授权追加更新。

## 5. 当前可交互范围

可切换五页、设置页签/语言/滑杆、日记滚动、历史语音筛选、人物卡示例取回。保存、生成日记、复听和导入空间等仍只在外部审阅区提示，不调用后端、不播放语音、不写玩家配置。返回链接进入已确认主场景预览，内页退场连续运镜尚未制作。

## 6. 确认不等于生产接入

本次确定的是第一轮视觉方案，正式Unity界面、聊天、记忆、人物卡和空间服务均未被替换。之后的工作应将采用稿映射到实际业务，校验动态遮挡、输入与滚动、长文可读性、多分辨率、字体交付、保存取消反馈等。需要精修时另建工作版本，不覆盖归档原图或误恢复薄信笺底板。
