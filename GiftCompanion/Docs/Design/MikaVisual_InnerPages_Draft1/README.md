## 日记如何比较

A/B正文、字体、字号、行距、位置、窗景完全一致，仅改变正文底层。两版均可滚动长文、点击“继续阅读”，并保留“回望至今”的手动总结入口，范围为开始使用至现在，而非只记录当天。示例文字不是实际对话或真实关系变化，不冒充已经生成的记忆。

可重点比较：文字是否清楚、是否过多挡住夜空、阅读底颜色/透明度是否合适、萝莉体用于长正文是否舒适。当前没有替玩家选定日记方案。

## 可点击范围

左侧导航和顶部审阅导航可以切换各页。设置页签、语言选项、滑杆示例、聊天“有语音”筛选、人物卡示例取回、日记滚动可用。保存、复听、资料、生成日记、添加空间等只显示审阅区提示，不调用后端、不播放语音、不写配置或玩家资料。返回未花链接到已有主场景预览，尚未做内页退场的连续运镜。
