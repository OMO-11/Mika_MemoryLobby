# V2 视觉与运镜设计合规审查

2026-11-03，Asia/Shanghai。依据根目录《项目总宪法.md》、V1 收尾总结与 checkpoint，以及指定的视觉归档进行本地审查。

## 1. 结论

**V2-0 更新：用户已明确保留新视觉，授权实现方对齐其他后端问题。初审提出的视觉条款差异已由[V2 差异决议](../02_执行记录/V2-0/V2差异决议.md)明确覆盖，输入、导航及维护入口已在[交互映射](../02_执行记录/V2-0/交互与能力入口映射.md)定案。V2-0 已完成；以下保留初审依据，原待定表述不再作为阶段阻塞。实际 Unity 接入与验证仍待后续阶段。**

**设计符合沉浸优先、轻量优先、共享角色与资源数据驱动的总体原则，适合作为 V2 视觉目标；严格逐条对照主宪法，仍有差异和未闭合交互，不能记为无条件完全符合。建议分七阶段推进。**

其中日期和字幕位置属于明确的视觉条款差异；聊天输入属于尚未完成的交互定义。设计报告记载玩家已认可视觉方向，但不能据此推断已批准删除 Enter 输入、Esc 菜单、退出或维护能力。阶段 0 先整理这些边界并由用户安排，之后进入实现。

工作量涉及实际 Spine 动画的分层与遮挡、坐标映射及点击、往返状态、字幕音频时序、五类内页和原有维护流程，并非几项字号颜色修改。浏览器原型的业务按钮大多为占位，不能将原型可点击当作 Unity 能力已交付。

## 2. 宪法与设计逐项对应

| 对照项 | 宪法依据 | 设计与判断 | 实施边界 |
|---|---|---|---|
| 场景优先 | §1.1、§13、§49 Phase3 | 人物与夜景为主体，功能移至窗边，方向符合 | 不引入常驻聊天面板、接口状态、加载百分比 |
| 轻量与技术栈 | §1.2、§2、§51 | 2.5D 参考无需新增大型框架，方向符合 | 使用现有 Unity/uGUI/TMP/Spine；HTML/CSS 是参考，不增加浏览器运行依赖 |
| 唯一角色 | §1.3、§4、§6、§40 | 原报告明确复用 Core，符合 | 窗边是 Companion 内部视图，不新建角色、数据库、LLM Session 或第二个模式 |
| 日期显示 | §13：Clock 建议 HH:mm，“不要添加天气、日期面板或 Dashboard” | 当前时钟另有 yyyy.MM.dd；虽不是独立日期面板，仍需明确解释边界 | 最严格默认只保留时间；若保留定稿的小型日期，记录为 V2 的明确视觉例外；不扩展为日历功能 |
| 字幕位置 | §13：“下方居中” | 定稿要求左下，与原文不同 | 如采用左下，记录 V2 视觉覆盖条款；只改变表现，保留可读性与时序 |
| 输入与打断 | §13、§18、§44、§50 | 移除了输入框视觉，替代方式明确标为未确认，尚不闭合 | 建议 Enter 唤出临时透明输入、Enter 发送、Shift+Enter 换行、Esc 取消；支持中文 IME、点击发送与打断，不默认引入语音输入 |
| 菜单与退出 | §13：Esc 菜单含 MomoTalk/Settings/Return Home/Exit | 窗边六项菜单没有退出与 Home；新增资料页来自既有 V1 能力 | 时钟点击作为增加入口，Esc 保持可用；退出与维护 Home 保留于可发现的二级操作，避免误把“回到未花”当作退出或 Home |
| Home 与桌宠 | §5、§50 的原始双模式入口 | V1 收尾已按用户要求改为直达陪伴、关闭桌宠，是既有有据覆盖 | V2 延续 companion/false，不因照抄早期宪法重新开放桌宠 |
| 思考与故障 | §14、§43、§44 | 定稿未完整示范异常状态，属于覆盖不足 | 沿用真实角色状态与自然反馈；声音不可用仍能文字聊天，设置可重试；缺动作按现有 Manifest 回退 |
| 声音、字幕、复听 | §17—20 | 定稿要求保留时序与缓存复听，符合 | 中文原文/正文、日语声音、单生产队列、迟到回调防护与 BGM ducking 均保留；无缓存禁用复听，不重合成 |
| 历史、日记、人物卡 | §7、§21—27 与 V1 收尾 §5 | 浮字日记只做阅读表现，手动回望至今，符合现有扩展 | 不自动生成、不虚构共同经历；更正/遗忘后的来源治理与人物卡保存边界保留，排版示例不写入正式数据 |
| 文件与空间配置 | §45、§51 与 V1 文件接口 | 原型已独立保存参数，方向符合 | 生产参数只设一个权威文件来源；按空间定义锚点，不把 CH0069 坐标套给所有导入空间 |
| 资源与字体 | §12、§19、§45 | 有原素材、字体来源、哈希与分层，便于复核 | 来源和哈希不能代替分发授权；沿用现有许可记录，交付时核对 Lolita/Georgia/Spine/BGM，缺字使用已有中文回退 |

本次不修改主宪法。阶段 0 应将用户最终选择写为单独的 V2 差异决议，标清被覆盖条款与适用范围；没有选择的项目保持待定，不将建议写成授权。

## 3. 视觉与素材审阅

已阅读主设计报告、内页设计总结、motion.json、已确认视觉规则、page_design.json，以及实现参考的分层导出代码；已查看窗边终点、浮字日记和设置资料页图片。

- 终点正向、整体退镜上抬、菜单左下与时间右上已经清楚，应以 CameraMotionV7 为构图基准，不恢复斜向终点或只缩字号的旧方案。
- 原型为 1280×720 逻辑画布的 Canvas 2.5D，缩放 2.3、旋转 -26.8165748° 与位移属于参考坐标；需要重新标定到 Unity，不能照抄为世界单位。
- room/character/curtains PNG 是定格分层。导出代码临时隐藏 Spine attachment 并捕获画面，不能证明正式动态 Spine 已具备同样的层级。生产必须验证人物动画、口型、触摸与遮挡，不能用静态人物图替换陪伴角色。
- 靠近人物的局部模糊、月光、轻纱、流星可以分开调整。减少动态效果需要真实支持，不能把 GIF 的固定往返时间变成产品自动返回计时器。
- 菜单 16、日期 12 等参考字号经投影后才是屏幕尺寸。需在实际窗口与 DPI 检查；全正文萝莉体配透明夜景也需长文复核，缺字、低对比度不能仅凭“字体加载成功”判为通过。
- 音乐中枢的完整按钮和字幕并未合并进运镜原型；内页未完成真实保存、复听、生成和导入。内页退场连续运镜也尚未制作，均纳入后续任务。
- 设计图片说明“回望至今”，应保持全程来源范围与手动生成，不因 UI 文案或小页面改变现有日记机制。薄信笺明确未采用，不恢复正文底板。
