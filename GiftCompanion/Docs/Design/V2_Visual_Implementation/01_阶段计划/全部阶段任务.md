## 2. V2-0：边界与交互定案

状态：已完成。以下保留原任务范围；本次最终决定以[差异决议](../02_执行记录/V2-0/V2差异决议.md)和[交互映射](../02_执行记录/V2-0/交互与能力入口映射.md)为准，原“建议”已转为明确实施规则，无阻塞定案项。

任务：

1. 对照审查表，形成日期、左下字幕相对主宪法的 V2 决议，保留原条款与选择理由。不把既有视觉认可推断为后端删减授权。
2. 明确输入方式。建议 Enter 唤起临时透明输入，Enter 发送，Shift+Enter 换行，Esc 取消；补点击发送、IME 选词与打断规则。输入框隐藏时不得失去聊天能力。
3. 定义 Companion、前进、窗边、内页、返回之间的行为表；明确返回时保留什么、何时停止点击、Esc 如何逐层退回，以及运镜期间收到回复/新输入的处理。
4. 确定真实角色命中、前景遮挡、窗边时间点击的优先级。人物前景挡住的时间不能通过头部误点穿透；提供 Esc 等备用入口。
5. 补齐退出、维护 Home、API Key、备份/恢复、记忆遗忘、语音重试、音乐导入/清单、单曲循环等入口映射。当前桌宠仍关闭。
6. 确认减少动态效果、直接到窗边与字体回退的呈现方式；把技术诊断保持在维护页。

产物：`V2差异决议.md`、`交互与能力入口映射.md`。验收：上述每项有确定行为或明确待定标记；影响实现的待定项未闭合时，不进入对应功能开发。

## 3. V2-1：视觉资源与配置基础

状态：已完成，资源、配置与静态标定见[阶段交付](../02_执行记录/V2-1/checkpoint.md)。以下保留原任务范围。

任务：

1. 将 Lolita 字体、独立图标和必要视觉参数接入正式资源目录，保留原素材；查明所需许可与发布记录。已有 Noto 中文作为缺字回退，验证中日文、标点与常用颜文字。
2. 建立轻量主题定义：暖白文字、粉色线条、透明控件、焦点/禁用/选中反馈、字号与间距。SVG 按现有 Unity 能力转换或接入，不为少量图标盲目加依赖。
3. 形成统一版本化视觉配置与每空间锚点/安全区；复用现有 JSON、原子保存和错误回退，不复制 HTML 内嵌参数为第二配置源。
4. 标定 1280×720 到当前相机与 Canvas 的映射，定义不同比例的裁切/留白规则；保留 V7 终点整体取景与 UI scale=1 的相对关系。
5. 为无窗边锚点的导入空间提供可用菜单回退；坏配置或字体缺失仍可进入维护页。

产物：配置契约、资源清单、人物起点与窗边终点静态截图。验收：配置可重载且无硬编码空间假设，实际文字可见、无方框、无新增 Core，冻结归档不变。

## 4. V2-2：动态分层与窗边运镜

状态：已完成，见[checkpoint](../02_执行记录/V2-2/checkpoint.md)及[实现与验证报告](../02_执行记录/V2-2/实现与验证报告.md)。V2-3/4 已随后完成；以下保留原任务范围。

任务：

1. 在现有 Spine 渲染基础上验证可行的场景分层方案；保留实际动画、口型、触摸与 Straight Alpha 表现，避免重复推进同一动画或修改导入源附件。
2. 实现人物与窗边两个取景状态，按参考标定中心、缩放、旋转、帘层与人物视差。中途经过人物，终点正向、退镜并上抬，无露空和边缘白块。
3. 时间与菜单固定在同一场景空间，接受真实前景遮挡；前进途中不替换成另一套屏幕 UI 或主动淡出。显示与命中使用相同映射。
4. 用轻量状态管理处理连续点击、反向返回、失焦、分辨率变化、退出及减少动态效果；窗边无限停留，返回由玩家触发。
5. 加入可调的微弱月光、轻纱、流星及近景模糊；限于窗面范围，避免大面积闪动。记录帧耗时，效果可单独关闭。
6. 接好 Esc 与窗边导航骨架，制作进入/退出内页的连续过渡，不重载 Companion 或重建角色会话。

产物：可运行运镜切片、起点/中间/终点截图与往返录屏、命中验证记录。验收：动态人物与前后遮挡正确；来回无跳变、无误触、不丢动画与 Core；减少动态效果可用。

## 5. V2-3：主场景输入、字幕与音乐

状态：已完成，见[阶段报告](../02_执行记录/V2-3/实现与验证报告.md)。联合 165 项逻辑、41 项场景和 31 项独立程序检查通过；未新验真实外部模型与完整设备范围。

任务：

1. 实现 V2-0 定案的临时输入视觉；保留草稿、IME、发送防重、取消与新轮打断。让透明输入与字幕互不遮挡，运镜不会提交半句输入。
2. 无框白色细描边字幕按已确认位置排版，移除厚底板和姓名条；保留字体设置、长回复分页、文本优先、无声音降级与自然淡出。
3. 继续使用现有中文交流/日语朗读链路；字幕随真实分段播放，不全文先显示后重新逐句播放。旧轮迟到回调不得覆盖新轮。
4. 左上显示真实曲名；上一首、播放/暂停、下一首、音量在鼠标靠近或键盘聚焦显现。双星/瑞士卷仅切装饰，不误切歌。
5. 保留空歌单、导入失败、单曲循环、手动切歌、淡化、静音与 speaking ducking，取消独立音乐主页仍有二级管理入口。
6. 复核 Thinking、Speaking、触摸、菜单与真实声音就绪状态；技术进度只去维护/诊断页。

产物：可真实使用的主场景、音乐状态截图、逐段字幕/打断记录。验收：中文输入可用、打断只产生一轮新请求；无语音可继续聊天；BGM 静音偏好不被恢复音量覆盖。

## 9. 范围约束与阶段记录

本轮不升级 Unity 和依赖，不改变模型/音色，不开放桌宠，不新增主动联网、语音输入、日历、养成数值或新记忆机制。若实现需要改变数据协议，先在对应阶段报告中说明兼容方案，不能将视觉工作扩成无关核心重写。

每阶段执行目录建议包含 `任务与变更.md`、`验证结果.md`、`checkpoint.md` 和 `截图/`。涉及生产代码后按主宪法 §51 同步架构、README 和开发日志；只有阶段实际通过，才更新为已完成。
