# V2-0 视觉差异与实现边界决议

2026-11-03，Asia/Shanghai。状态：设计与交互定案完成；生产代码待后续阶段实现。

## 1. 本次依据

用户明确安排：“关于v2-0，视觉效果方面保留新修改方案，其他后端问题交由你进行对齐”。本次据此保留已确认视觉，并由实现方闭合输入、导航、生命周期与既有能力入口。此授权适用于 V2-0 定案，不自动执行 V2-1—V2-6。

本决议是主宪法在 V2 视觉范围内的补充；原宪法保留。未被本决议明确覆盖的架构、数据、取消、隐私与权限要求继续有效。冻结视觉归档原件保留，后续实现引用本决议及归档共同作为依据。

## 2. 保留的新视觉

| 项目 | V2 定案 | 与主宪法的关系 |
|---|---|---|
| 时间与日期 | 窗边右上 HH : mm，下方 yyyy.MM.dd；以本机本地时间为生产默认，当前上海环境即 Asia/Shanghai | §13 日期相关限制在这一个场景文字元素上做局部覆盖；不增加日历或日期面板 |
| 字幕 | 左下、白色细描边、透明，无厚底板与姓名条 | 覆盖 §13 下方居中的位置要求，分句/朗读时序仍有效 |
| 窗边菜单 | 聊天记录、日记、陪伴空间、人物设定、设置、回到未花，共六项 | 保留功能与空间布局；Esc 仍能访问，退出和维护放入二级设置 |
| 运镜 | CameraMotionV7 为基准：经过人物，终点正面、整体退镜上抬，真实前景遮挡；UI 独立缩放为 1 | 属于 Companion 内部视图，不能新建角色核心或另开模式 |
| 音乐 | 左上实际曲名、透明靠近/焦点显现控件、双星/瑞士卷装饰切换 | 保留已有音乐后台能力；主场景不增加歌单、封面或独立音乐主页 |
| 内页 | 萝莉体、暖白浮字、透明控件；日记采用浮字版 | 可读性通过字号、描边、背景细节强度和缺字回退调整，不擅自恢复薄信笺或大型底板 |
| 输入 | 平时隐藏；需要时出现临时透明文字输入与轻量发送入口 | 删除常驻输入框外观，不删除 §13、§18、§50 的键盘输入与打断能力 |

日期按当前设备的日常时间解释，不在产品界面加入时区面板。可复现截图仍允许固定示例时间，但正式运行必须读取真实时间，不能照搬 21 : 06 或 2026.11.02。

## 3. 由实现方确定的功能衔接

1. Enter 唤起临时输入；再次 Enter 发送，Shift+Enter 换行；中文 IME 组合期间 Enter 只确认候选，不能发送。保留轻量点击发送入口，输入为空不发请求。
2. Esc 优先关闭输入并保留本次运行内草稿；内页逐级返回窗边，窗边返回人物；人物视角 Esc 前往窗边。输入与导航规则见同目录交互表。
3. 窗边及内页属于同一 Companion 会话，普通翻页和运镜不重建 Core、数据库或语音服务。对话继续接收和保存，不能因镜头切换丢弃回复或从头重播。
4. “回到未花”只切人物取景。退出位于“设置 → 资料 → 退出应用”；维护 Home 位于“设置 → 资料 → 应用维护”。两者分别复用现有安全退出和维护切换流程，不能只关闭画面或直接结束进程。
5. “设置 → 资料”集中连接配置、备份恢复、资料检查、记忆管理、音乐文件管理等二级能力。技术状态仍在维护/诊断区域。
6. 减少动态效果设于“设置 → 画面与阅读”，默认关闭。开启后按原取景直接到达目标，省略推进/旋转、近景模糊、流星与附加纱帘摆动；保留基础 Spine 待机和必要角色反馈。所有导航入口共用该偏好。
7. 萝莉体优先；缺字回退已有 Noto 中文。极端字号用滚动/换行与安全区解决，不裁掉操作；授权记录在资源接入/交付阶段核对。

## 4. 后端不变量

继续使用唯一 AppRoot/CharacterCore、现有中文对话与日语声音链路、单 TTS 生产队列、缓存复听优先级、BGM ducking、来源受限记忆、手动全程日记和配置原子保存。UI 调用现有服务，不直接访问数据库或发送 HTTP。

启动维持 companion/false，桌宠关闭。数据库 schema v10 与备份格式 v1 作为当前兼容基线；本次定案不迁移数据库、不换模型/音色、不重置人物与记忆。

新增显示偏好将由 V2-1 定义兼容的版本化文件契约，不提前向正式 UserData 写入试验配置。所有网络与异步操作继续使用现有 Timeout、CancellationToken 和轮次/视图有效性检查。

## 5. 阶段结论

审查中的视觉条款差异现已获得用户授权；输入、退出、维护、命中与异步衔接已有确定规则，V2-0 无阻塞定案项。后续若发现无法等效实现的视觉变化，应先记录实际限制与替代效果，不能自行回退旧视觉。

本阶段完成的是决议与接口行为定义，不代表 Unity 视觉已接入或后端改动已通过运行验证。具体实现与验证分别落在 V2-1—V2-6。
