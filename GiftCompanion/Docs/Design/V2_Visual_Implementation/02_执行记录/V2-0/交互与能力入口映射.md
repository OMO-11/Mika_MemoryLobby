# V2-0 交互与原有能力入口映射

2026-11-03，Asia/Shanghai。以下是实施契约，代码现状与后续实现分开记录；本文件不声明这些 V2 行为已在程序运行。

## 1. 输入与导航

| 当前状态 | 操作 | 确定行为 |
|---|---|---|
| 人物视角、输入关闭 | Enter | 临时透明输入淡入并聚焦，恢复本次运行内草稿 |
| 输入中 | Enter / 点击发送 | IME 未组合且非空时发送；清空已提交草稿并收起输入，按原流程开始新轮 |
| 输入中 | Shift+Enter | 换行，不提交 |
| IME 组合中 | Enter / Esc | 先交给候选确认/取消；消费本次按键，不能同时发送、关输入或运镜 |
| 输入中 | Esc | 收起输入，保留未发送草稿；不取消当前实时回复 |
| 人物视角 | 点击可见时钟 / Esc | 关闭人物触摸捕获，前往窗边；对话与声音继续 |
| 前进或返回中 | 同向重复点击 | 忽略重复目标，不叠加协程或跳变 |
| 前进或返回中 | Esc | 以人物视角为目标，从当前插值位置连续返回；重复 Esc 不反复翻转 |
| 运镜中 | Enter | 记录一次“返回人物并输入”的意图，平滑返回，到达后才聚焦；Esc 清除该意图；不缓存实际文字按键 |
| 窗边 | Enter | 返回人物后打开临时输入；焦点已在按钮上时由按钮消费，不抢占控件激活 |
| 窗边 | 菜单项目 | 打开对应内页；“回到未花”返回人物视角 |
| 窗边 | Esc | 返回人物视角 |
| 内页/二级页 | Esc / 返回 | 先关弹层或二级页，再回窗边；不一次跨多层 |
| 内页字段/滑杆/列表 | Enter / 方向键 / 滚轮 | 由当前控件处理；不触发隐藏聊天输入或背景相机 |
| 任意状态 | 失焦 | 取消触摸/按压与导航快捷键捕获，不发送、不丢草稿；运镜在当前进度暂停，重新聚焦后继续 |
| 任意状态 | 调整窗口/DPI | 从逻辑坐标重算投影、裁切与命中，保留当前运镜进度与页面；避免在旧坐标上执行点击 |

输入首帧与组合结束帧仍使用现有防重保护。草稿只在当前进程内保留，不自动写入聊天、人物卡或长期记忆。文本失败按现有规则恢复可重试输入，不因导航重复请求。

命中优先级：弹层/当前页面与控件 → 可见音乐控件或场景菜单 → 角色实际命中区域 → 可见且未被前景遮挡的时钟 → 空白。人物挡住时钟时不穿透触发导航；音乐/字幕装饰不扩大为整屏拦截区。窗边/运镜中角色触摸停用，回人物后再恢复。

## 2. 对话、语音与异步生命周期

| 事件 | 后端处理 |
|---|---|
| 普通运镜/开内页 | 不取消实时轮次；继续接收、持久化中文正文并按原队列播放。人物取景以外隐藏陪伴字幕，不强塞进内页正文 |
| 返回人物时仍在朗读 | 显示当前实际朗读段；不从首句重放。已经结束的内容可从聊天记录阅读/复听，不补播错过片段 |
| 输入新消息并发送 | 复用现有 StopSpeech、旧轮 CancellationToken、generation 与等待旧任务流程；旧轮迟到内容不能覆盖新轮 |
| 打开输入但未发送 | 不打断当前回复；临时输入与字幕避免重叠，发送才开始新轮 |
| “先看文字” | 只停止本轮声音并展示同一轮文字，下一轮恢复既有语音偏好；保留轻量上下文入口，不显示预热秒数 |
| 无 Key / 声音失败 | 沿用自然反馈、文字降级和设置重试；不在场景显示 HTTP、TTS 进度或堆栈 |
| 历史复听 | 完整缓存可用才启用；实时对话进行中不抢占；离开历史页停止该页复听，不能停止无关的实时轮次 |
| 离开内页 | 取消页面查询、加载或未完成生成，保存日记阅读位置；检查取消与视图代次后才能回写 UI |
| 设置/人物卡离页 | 有修改且未保存时，在当前页内给出“继续编辑 / 放弃修改并返回”；不静默保存。放弃时撤销可预览的音量/显示草稿 |
| 保存或导入中 | 防重复操作；可取消部分取消后回页。已进入原子提交的部分先完成/回滚，得到确定结果后才离页；不显示假成功 |
| 进入维护/恢复/退出 | 调用现有维护或离开流程，取消并等待活动任务、停止语音与复听、保存状态；恢复先校验预览与确认，不能在活动数据库上直接替换 |

运镜使用独立视图状态，不能伪装成 CharacterMode 切换。对话轮、页面任务和运镜各自持有生命周期，页面关闭不能顺带取消 Core 全局令牌。减少动态效果时同样执行页面取消、焦点和保存规则，不跳过必要业务收尾。

## 3. 原能力与新入口

| 原能力 | V2 入口 | 复用依据 / 所属实现阶段 |
|---|---|---|
| 中文发送、IME、防重与新轮打断 | 人物临时输入；窗边 Enter 返回后输入 | CompanionScreen.OpenInput/SendAsync、CompanionInputGuard；V2-3 |
| 字幕、先看文字、默认语言 | 人物字幕上下文；设置 → 声音 | CompanionVoiceUI、CompanionVoicePlayer；V2-3、V2-5 |
| 时钟、菜单与返回人物 | 可见时钟/Esc；窗边六项菜单 | 新视图状态复用 Companion 现有实例；V2-2 |
| 曲名、切歌、播放/暂停、音量 | 左上音乐中枢；靠近或键盘焦点展开 | BgmManager/BgmFilePlayer；V2-3 |
| 添加/选择/移出歌曲、单曲循环 | 设置 → 资料 → 音乐文件管理，在该子页展开清单 | root.Library.Music、导入/保存服务；V2-5。属于资料维护，不新增主场景音乐主页 |
| 历史分页、复听、本轮不参与回忆 | 聊天记录 → 具体消息操作 | CompanionPanels、History、现有复听/遗忘流程；V2-4 |
| 查看/移除长期记忆 | 设置 → 资料 → 记住的内容 | 既有 MemoryService 与明确对象确认；V2-5 |
| 日记旧篇/滚动/继续/打开 MD | 日记 | root.Diary、现有阅读位置与导出同步；V2-4 |
| 全程回望与停止整理 | 日记 → 回望至今 / 停止整理 | 现有手动生成、来源治理、DB+MD；V2-4 |
| 名称、称呼、性格与关系设置 | 人物设定 → 保存 / 取回 | 现有 CharacterIdentity 与 SaveCharacterCardAsync/ReloadCharacterCardAsync；V2-5 |
| 场景选择、添加、校验与失败回退 | 陪伴空间 | root.Library.Spaces、CompanionPresentation.SwitchSpaceAsync；V2-5 |
| 画面/阅读字号、行距与减少动态 | 设置 → 画面与阅读 | 既有 CompanionDisplayService + V2-1 新偏好文件契约；V2-5 |
| Key 配置、连接测试、重读配置 | 设置 → 资料 → 连接设置 / 资料检查 | PlayerMaintenance.OpenFromMode，经 Home 安全维护路径；V2-5 |
| 备份、检查、恢复预览/确认与恢复点 | 设置 → 资料 → 备份与恢复 | 现有 Backups 与维护事务，保持资料回溯提示；V2-5 |
| 配置重置、上版恢复与保留原件 | 设置 → 资料 → 资料检查 | PlayerConfigRecovery、明确项目确认；V2-5 |
| 语音重试、缓存管理与脱敏诊断 | 设置 → 声音 / 资料 → 资料检查 | 现有声音维护/缓存管理/诊断；V2-5 |
| 打开玩家文件目录 | 设置 → 资料 → 资料文件夹 | PlayerFiles + root.Config.UserDataPath；V2-5 |
| 维护 Home | 设置 → 资料 → 应用维护 | PlayerMaintenance.OpenFromMode / LeaveForMaintenanceAsync；V2-5 |
| 退出 | 设置 → 资料 → 退出应用；系统关闭按钮 | 现有 LeaveAsync/统一退出与保存链路；V2-2 接基础路由、V2-5 完成页面 |

人物设定中显示的名字/称呼/关系基调/说话方式是已有配置的编辑投影；先映射现有字段，不凭视觉拆分擅自改数据库或 Identity 协议。具体控件与序列化映射在 V2-5 接入时验证。

## 4. 实现检查点

已核对现有 CompanionScreen 的输入/发送/轮次取消、CompanionPanels 的页内令牌与记忆入口、CompanionLibraryPanels 的音乐/空间/人物卡/日记操作、PlayerMaintenance 的维护导航与备份恢复，以及 AppEntrySettings 的 companion/false 默认值。
