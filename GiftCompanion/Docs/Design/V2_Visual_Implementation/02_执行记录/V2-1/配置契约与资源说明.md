# V2-1 视觉配置契约与资源接入

2026-11-03，Asia/Shanghai。对应 V2-1 的五项任务；运行基础已接入，实际动态运镜与整套页面替换由后续阶段完成。

## 1. 文件与加载

默认定义唯一来源：`Assets/App/Companion/Resources/MikaVisual/visual_defaults.json`。AppRoot 在加载既有显示配置后创建唯一 `VisualSettings`，从打包 Resources 获取默认 JSON，通过 `CompanionVisualService` 读取玩家可选的 `Config/companion_visual.json`。代码不再内嵌第二套主题/取景数值。

玩家文件不存在时仅使用随包默认值，不在启动时写新文件；保存时使用现有 AtomicDocument，校验后原子提交并保留上一版。Load 可重载；损坏、未知版本或不可读文件保留原件，继续使用本次进程最后有效配置。新启动遇到损坏配置则使用随包默认。问题通过 Issue 留给维护页，场景中不显示解析异常。

现有 `companion_display.json` 的曝光、日记字号和行距保持原职责；新文件只承担视觉主题、减少动态效果偏好与空间锚点。数据库和备份版本未变。新文件位于 Config 目录，沿用目录型备份规则；维护页的编辑/恢复项目登记和偏好控件在 V2-5 接入。

## 2. v1 字段

| 字段 | 定义与范围 |
|---|---|
| Version | 必须为 1；不猜测未来版本 |
| ReduceMotion | bool，默认 false；V2-2/5 消费此偏好实现直接到达与减少附加效果 |
| Theme.Ink / ClockInk / Accent / Focus | 六位 #RRGGBB；分别为文字、时间、强调与焦点 |
| Theme.DisabledAlpha / MenuAlpha / ClockAlpha | 0—1；已确认菜单 .78、时间 .76 |
| Theme.MenuSize / ClockSize / DateSize / BodySize | 逻辑字号，默认 16/32/12/20，校验 10—72 |
| Theme.RowHeight | 逻辑行距，默认 18.5，校验 10—72 |
| Spaces | 最多 128 项，ID 精确且唯一；每项独立校验，任何坏项拒绝整份配置 |
| Spaces[].Id | 与现有 companion_spaces.json 的空间 ID 对应；内置为 mika-memory |
| CenterX / CenterY | 原图逻辑中心，x 0—1280，y 0—720 |
| Zoom / Rotation | 缩放 1—4、角度 -90—90；当前 2.3/-26.8165748 |
| MenuX/Y、ClockX/Y、UiAngle | 该空间文字锚点与角度，当前 845/195、1060/190、26.8165748 |
| SafeLeft/Top/Right/Bottom | 空间 UI 安全边距，各 0—180；当前 24，供后续视图布局消费 |

所有数值拒绝 NaN/Infinity。Save 复制传入配置再保存，调用方改动草稿不会悄悄修改已保存的服务值。后续编辑页应使用独立草稿，取消时丢弃，不能直接修改 Value。

## 3. 逻辑坐标、Canvas 与回退

逻辑坐标固定 1280×720，左上为 (0,0)，y 向下。Project 以起始中心 (640,360) 向配置终点中心插值，在配置角度下旋转并缩放；Unproject 使用同一变换的逆。传入进度为 0—1 的已缓动值，函数不自行增加第二层 easing。

以居中 Canvas 显示时位置为 `(x-640,360-y)`，图像角度使用逻辑角度的负值。UI 同步叠加 UiAngle，使终点正向；UI 独立缩放仍为 1，屏幕大小变化来自镜头缩放。TMP 的上对齐字形与浏览器基线存在差异，菜单工厂使用 1.1 倍字号的基线校准，当前起点/终点已截图复核；字体改变时需重新查看，不代表所有字体都通用。

Viewport 对宽高取 `min(width/1280,height/720)` 的等比 Fit，额外区域留白；不拉伸图像，也不凭空扩充背景。已检查 1280×720、1920×1080、2560×1080、800×800 的计算。实际 Player/DPI 适配仍在 V2-6 验证。

`FindSpace(id)` 只按空间 ID 查找；未知空间返回 null，不套用 CH0069 的窗边坐标。`CompanionVisualFoundation.CreateMenu` 可在未知空间生成屏幕位置菜单并由调用方注入现有业务回调；设置按钮回调已验证。V2-2 将此基础接到真实导航、EventSystem、遮挡与窗口变化流程。此阶段截图中的回退按钮不是已发布应用的新菜单。

## 4. 资源与许可记录

正式资源目录为 `Assets/App/Companion/Resources/MikaVisual`。已复制用户提供的 Lolita.ttf、三张定格参考分层、独立默认参数、七枚 SVG 文本原件及其 256×256 透明 PNG。PNG 由本机 Edge 渲染原 SVG，Unity 按 Single Sprite、透明、无压缩导入；无新包依赖。重建脚本为 `Tools/Prepare-V2VisualIcons.mjs`。

Lolita 动态 TMP 字体使用现有 Noto 中文作为 fallback，多 atlas；原有 UI 工厂默认字体不整体切换。样本文字覆盖中文菜单、日语、标点与常用颜文字，不等于覆盖所有 Unicode。缺少 Lolita 资源时工厂直接返回现有中文字体。按钮使用主题中的 normal/highlight/selected/pressed/disabled 反馈。

资源来源和 SHA256 见 `资源来源.json`。Lolita 原始记录仅说明用户提供，未附明确再分发许可，本阶段记录为开发集成，V2-6 封装前核对。Georgia 字体未复制，当前也未完成曲名字体接入；后续音乐中枢可使用已获授权资源或已有中文回退。Noto 继续使用工程已有 OFL 文件；Spine/BGM 沿用既有许可记录，不重复导入原骨架或音频。

三张分层只用于本阶段静态标定。没有用定格人物替换生产 Spine；真实动画分层与前景遮挡仍属于 V2-2。冻结视觉目录的 96 个清单项已重算 SHA256，全部保持一致。
