## 2. 渲染实现

`CompanionWindowView` 绑定当前实际 Loader，使用 Spine 自带 SkeletonRenderSeparator，将连续绘制槽分为背景、帘子与人物组。当前内置场景得到 8 段网格，4 段属于前景。所有分段共享唯一 SkeletonAnimation、AnimationState、骨骼姿态与原贴图，分段变换不再推进一次动画，也不改 Spine 资源附件。

背景深度 1、帘子 1.05、人物 2.5，人物追加逻辑位移 (-700,300)×进度平方。位移、角度、缩放和节奏从空间配置读取，再按同一投影转换到场景单位。逻辑摄影机轨迹映射到各组网格和世界 Canvas，避免改变共享骨骼或破坏触摸/口型引用。终点仍为 V7 的正向、整体退镜上抬构图。

菜单和时钟从起点起就存在于同一个世界 Canvas，排序在背景和真实前景之间；镜头移动时未替换另一套屏幕界面。菜单文字本身维持 .78，时间 .76，遮挡来自前景网格。内页打开后菜单退出交互，旧内页在上层呈现；后续浮字阅读页将复用该入口。

世界菜单通过真实 uGUI Button 回调打开历史、日记、空间、人物卡与设置；“回到未花”只返回人物视角。设置保留应用维护与退出，既有安全收尾链路继续有效。缺少锚点的空间使用屏幕菜单回退，空间切换后重新绑定新 Loader，并避免重复创建维护按钮。

## 3. 命中、导航与生命周期

时钟点击采用与显示一致的逆投影和局部旋转；菜单射线经过前景过滤。过滤逐个核对分段网格三角形、重心插值后的贴图 UV 和透明度。当前阈值为有效 alpha > .6：不透明人物/窗框阻挡点击，轻薄半透明帘子允许操作仍能辨认的文字；阈值可后续按实际体验微调。

人物视角启用原触摸；运镜、菜单或内页接管时取消触摸捕获。Enter 在窗边发起返回并在到达后唤起原输入；重复前进请求不叠加动画；Esc 可中途反向返回。位置连续，不重建场景或角色核心。窗边一直停留，直到玩家返回。

失焦暂停运镜，重新聚焦继续。窗口变化按当前尺寸重算等比 Fit 与相机 viewport，附加清屏相机保证黑色留白。显示和命中共享实际相机 viewport，不使用旧窗口尺寸。该清屏相机不创建角色、会话或语音服务。

内页进入使用淡入与轻微缩放，离开在立即取消页面任务、关闭交互后淡出。每个页面拥有视图代次，快速关闭/重开时旧退场协程不得把新页面隐藏。普通运镜和翻页保持 Core、数据库、活动轮次与 AnimationState；真正维护、退出仍走原有保存/取消流程。

## 4. 效果和配置

`companion_visual.json` 继续 Version=1，在原契约上新增可选字段，旧 v1 配置通过兼容默认值继续读取：

| 字段 | 默认值与用途 |
|---|---|
| EffectStrength | .6，0—1；0 可关闭附加效果强度 |
| Moonlight / Sheer / Meteors / NearBlur | 各 true，可分别关闭月光、附加纱帘、流星和近景模糊 |
| Spaces[].ForwardSeconds / ReturnSeconds | 3.2 / 2.4，允许 .1—10 秒 |
| CurtainDepth / CharacterDepth | 1.05 / 2.5，允许 1—4 |
| CharacterOffsetX / Y | -700 / 300，允许 -2000—2000 逻辑像素 |
| Pane | 八个数表示窗面四角；控制附加环境效果的裁切范围 |

附加效果由轻量 Shader 完成：柔和月光、慢摆细纱、间歇两道流星以及仅作用于人物分段的近景模糊。窗面四角来自该空间配置。效果 Material 放在 Resources，保证独立构建保留 Shader，不依赖编辑器可见但 Player 被裁掉的资源。

“设置 → 画面与阅读 → 减少动态效果”可立即保存偏好；开启后直接到达目标，关闭附加动态/模糊，基础 Spine 动画继续。当前控件沿用 V1 页面，其最终视觉与保存体验在 V2-5 统一整理。具体特效开关本阶段可通过配置调整。
