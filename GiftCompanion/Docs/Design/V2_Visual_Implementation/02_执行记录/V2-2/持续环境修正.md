# V2-2 终点持续动态修正

2026-11-03，Asia/Shanghai。用户要求到达窗边后细纱、星空与流星继续动态播放，人物与菜单间连续切换。

已将环境动画时钟从镜头进度与失焦暂停逻辑中分离：人物取景、运镜、窗边停留、内页打开及返回均持续推进同一时钟。切换目标不重置环境相位；失焦只暂停运镜，环境继续更新。星空补充低幅度星点明暗变化，流星仍按环境周期出现，细纱持续缓摆。玩家主动开启“减少动态效果”时继续尊重其设置。

此前 Windows 演示在停留和内页操作期间没有持续采帧，导致 GIF 出现长时间定格。新录制完整覆盖 10 秒窗边停留与内页过渡，并在往返录制结束后才执行窗口缩放检查，避免将测试空档编码为静止画面。

[查看新的持续动态演示](Windows持续环境往返演示.gif)：151 帧，约 16.13 秒，960×540；按实际采集间隔编码，最长单帧 240 ms。原 53 帧演示保留为历史，不再代表当前修正效果。窗口停留的第 50/65 帧在排除时钟的窗景区域像素不同，记录见 continuous_recording.json；复核图已查看。GIF 末尾循环属于演示文件，产品仍由玩家主动返回。

验证通过：更新后的运镜专项 24 项检查（continuous.PlayMode.xml / motion_validation.json），独立 Windows 15 项（NativeContinuous/native.json）。新增检查覆盖终点持续时钟、失焦环境推进、内页动画延续与返回不重置。独立程序在窗边实际停留 10 秒后正常保存退出，未启动声音或真实 API。

当前构建仍位于 Builds/V2Window，属于无独立语音 Runtime 的图形验证切片。新二进制清单为 continuous_build_files.json，结果为 continuous_acceptance.json；原 acceptance.json、build_files.json、Native/ 与首版 GIF 是前一候选的历史证据。未推进 V2-3。
