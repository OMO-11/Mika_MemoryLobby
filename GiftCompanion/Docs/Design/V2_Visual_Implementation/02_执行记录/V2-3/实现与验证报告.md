# V2-3 主场景输入、字幕与音乐中枢

2026-11-03，Asia/Shanghai。本阶段与 V2-4 一起实施，接入正式 Unity 运行代码；完成后按用户安排执行本机休眠。

## 1. 已实现行为

输入平时隐藏，Enter 唤出临时透明输入，Enter 发送、Shift+Enter 换行，保留原中文 IME 与防重复提交保护。Esc 收起时保留草稿，输入淡出后隐藏；再次打开不会全选覆盖原草稿。运镜返回到人物后才聚焦，镜头不会自动发送文字。聚焦音乐按钮时，Enter 留给按钮处理；主场景 Tab 可进入音乐区域，Tab/Shift+Tab 在其可用控件间移动。

字幕改为左下白色细描边，透明且无姓名条。原分段队列、播放事件、分页、字幕字号、文本优先与新轮打断沿用原链路；声音没有就绪时仍可文字交流。先看文字保留为低干扰文字操作，停止本轮声音后继续同一回复，后续回复仍遵循保存的语音偏好。

音乐中枢左上显示实际曲名，Georgia 斜体优先，中文缺字由现有 Noto 字体回退；未安装 Georgia 时使用已有字体。只显示透明的上一首、暂停/继续、下一首、音量。靠近或键盘聚焦时显现，移开并离开焦点后收起；双星/瑞士卷按钮只切装饰，不改曲目。

BgmManager 新增真正 Pause/UnPause，保持播放位置；暂停中的淡化与交叉切歌时间同步暂停，恢复时校正 DSP 起点。退出时若音乐暂停则直接停止，避免等待一个已暂停的淡出队列。静音、音量与说话 ducking 继续独立管理，暂停/恢复不替玩家取消静音。

音量拖动即时预览，松手保存，并有短延迟合并键盘/连续调节；正常离开前刷入待保存值。空歌单仍可设置音量/静音；无可播放音频时禁用暂停，但只要清单有歌曲仍允许尝试前后切换。无效导入保留当前可用歌曲。音乐文件管理保留在“设置 → 音乐文件管理”，其维护页面暂沿用原布局，V2-5 再统一设置分组与外观；主场景没有恢复歌单、封面或音乐主页。
