# V2-5 设置、人物与空间维护

2026-11-03，Asia/Shanghai。用户确认 V2-3/4 完成后，授权开始本阶段。范围遵循 V2-0 决议和全部阶段任务；V2-6 的完整独立分发、设备/DPI矩阵及长期体验仍另行安排。

| 页面或操作 | 现有服务与资料 | V2 呈现和生命周期 |
|---|---|---|
| 设置 → 声音 | Config/settings.json、CompanionVoicePlayer、BgmManager | 角色音量、开关、语言、背景音量与静音；即时音量预览，显式保存；默认值仅预览，取回读取保存值 |
| 设置 → 画面与阅读 | CompanionDisplayService、settings.json、CompanionVisualService | 亮度、高光柔和、日记字号/行距、字幕字号、减少动态；独立草稿，离页可撤回，保存失败回滚先前写入项 |
| 人物设定 | CharacterIdentity、ConfigService、AppRoot.PlayerWorkAsync | 名字 → DisplayName；性格与说话方式 → Persona；对你的称呼与关系基调 → Relationship；Id 固定，原文本不拆分、不猜测，不写示例默认 |
| 人物取回与上一版 | ReloadCharacterCardAsync、PlayerConfigRecovery | 取回文件中版本先确认草稿替换；上一版与保留原件通过资料检查的原有流程恢复，不把重新读取冒充上一版恢复 |
| 陪伴空间 | ContentLibrary、CompanionPresentation.SwitchSpaceAsync | 实际名称、当前取景缩略图、导入、清单与选择；校验失败保留原空间；换场后重建对应窗边视图，复用角色和数据库 |
| 无窗边适配的空间 | V2 菜单回退 | 基础待机与回退菜单可用；内页增加全幅阅读遮暗，避免浮字落在亮色人物上无法辨认 |
| 设置 → 资料 → 音乐文件管理 | BgmFilePlayer、ContentLibrary | 二级浮字清单；添加、选择、单曲循环和移出。移出先显示曲名确认，原文件保留 |
| 设置 → 资料 → 记住的内容 | ISharedMemoryService、CharacterCore | 显示实际记忆，移除前确认具体正文；取消不改资料，确认后原始聊天保留 |
| 语音缓存清理 | AudioCache、语音 DrainAsync | 明确说明清理后旧语音无法复听，先确认，再停止朗读并等待正在进行的合成收尾 |
| 资料文件夹、素材与日记文件 | PlayerFiles、Library、Diary | 可打开目录、重读清单和导出检查报告；重读经过原服务，错误反馈不显示堆栈或 Key |
| 连接设置 | PlayerMaintenance.Page.Connection | 经安全维护 Home 进入，直接打开联网页；Key 继续为掩码字段、本机加密，保存和联网测试分开 |
| 备份与恢复、恢复点 | PlayerMaintenance.Page.Backup、Backups | 原备份创建、校验、预览、确认、恢复前备份和重启事务；Backups、RestorePoints、ConfigRecovery 三个位置均可达 |
| 配置原件/上一版、诊断 | PlayerMaintenance.Page.Health、ConfigResetSelection | 精确项目名及文件名确认；换对象取消旧确认；保留原件、重置/上一版和脱敏诊断路径不变 |
| 应用维护、退出/系统关闭 | 原模式控制、LeaveAsync、AppRoot.ShutdownAsync | 先收尾自有任务并保存；未保存编辑先询问，正在提交时阻止重复离页。默认 companion/false 不变 |

所有正常内页共用已确认的暖白浮字、萝莉体与现有 Noto 回退、左侧导航和细线控件。表单可滚动，Tab/Shift+Tab 按页面顺序移动并将控件滚到可见区域；Esc 先关闭确认，二级页先回资料，再回窗边。仅维护 Home 保留已有安全工具界面，不替换其恢复事务。

页面草稿与配置对象分离。减少动态效果的预览只改当前视图，不再改服务中的已保存对象；窗边细纱、星空、流星的独立时间线保留。离页回调受当前页面令牌约束，提交中的操作先得到确定结果，避免取消后假成功或旧页面回写。

本阶段验证均使用隔离 Validation 资料；验证人物名、记忆、空间与音乐操作不进入玩家正式资料。当前新结果以同目录 acceptance.json、Native/native.json 和验证报告为准。
