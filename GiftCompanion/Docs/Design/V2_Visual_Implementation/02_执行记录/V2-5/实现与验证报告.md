## 已实现

设置分为声音、画面与阅读、资料三组页签。正常内页保留萝莉体、暖白文字、细线控件和左侧导航；长表单可滚动，细滚动条提示下方还有内容。Tab/Shift+Tab 可在页面控件间移动并滚动到所选控件；Esc 先取消确认，再从二级页回资料、从主内页回窗边。

声音页保留角色音量、语音开关/语言、背景音乐音量/静音、停止回复/复听、重试、缓存与说明。音量立即预览，保存才写入；恢复默认只改变草稿，取回读取已保存值。画面与阅读页保留亮度、高光柔和、日记字号/行距、字幕字号、减少动态和原版画面预览。减少动态的预览与配置对象分离，放弃修改恢复已保存值，环境独立时间线继续保留。

设置或人物卡有未保存修改时，切页、左侧导航、返回和系统关闭先显示“继续编辑 / 放弃修改并返回”。保存/导入等提交中防重复离页；可以取消的日记生成仍允许离页取消，点击停止整理等待原工作收尾后重新打开可用页面，避免留下已取消的页面令牌。输入焦点在换页时释放，不将旧控件按键带进新页面。

画面与阅读涉及现有三个配置文件，逐文件原子写入，后一步失败时补偿回滚先前写入的保存值，保留当前草稿供重试；回滚失败明确提示取回核对。此处没有新增配置格式，也不宣称多个文件构成断电时的整体原子事务。场景测试用独占锁制造显示文件保存失败，核对前一配置撤回、草稿保留及释放锁后的重试。

人物卡按下划线字段编辑真实配置：名字对应 DisplayName，性格与说话方式对应 Persona，称呼与关系基调共同对应 Relationship。原协议没有独立称呼字段，因此不从原文猜测或拆分，也不填设计稿示例。保存通过原 AppRoot.PlayerWorkAsync 应用到同一角色；名字为空不能替换。取回文件版本先确认覆盖本页草稿，上一版与原件通过资料检查的现有恢复流程处理。

陪伴空间显示实际名称、当前取景缩略图、导入、清单与选择。有效资源通过原 Spine 校验和选择提交，失败保留原可用空间；换空间后更新对应窗边视图，角色与数据库保持不变。没有窗边适配的空间继续使用基础待机与回退菜单，其内页加入全幅阅读遮暗，保证亮色人物背景上的文字仍可辨认，未恢复正文底板。

资料页接回音乐文件管理、记住的内容、文件目录、素材/日记检查、连接设置、备份恢复、恢复点、配置原件、上一版、脱敏诊断、维护 Home 和退出。音乐移出、记忆移除和语音缓存清理均先说明准确对象和后果。Key、备份恢复与配置重置继续经过原安全维护 Home，直接落到请求的子页，保留校验预览、明确确认、原件保留和重启事务。
