# 放大窗口黑边修正

2026-11-03，Asia/Shanghai。根据玩家最大化截图调整 V2-1 原先的整幅 Fit 规则；这是 V2-5 的体验修正，V2-6 仍待安排。

原先场景相机使用居中的 16:9 视口，窗口变宽时两侧由清屏相机填黑。现在场景等比铺满整个客户区，超出窗口的少量边缘居中裁切，不拉伸人物；16:9 构图保持原比例。取消额外的黑色清屏相机，按基准尺寸计算正交视野，窗口连续变化不累计缩放。

场景运镜仍使用原逻辑坐标；时钟点击按铺满后的坐标逆映射，前景遮挡和世界菜单继续使用实际相机。屏幕内的输入、字幕、表单仍完整适配，避免随背景裁切而丢失按钮；确认遮罩与无窗边空间的阅读遮暗覆盖全窗口。环境独立时间线保持连续。

当前修正程序仍在 `Builds/V2Maintenance/GiftCompanion.exe`。本目录的 acceptance.json、build_files.json、Native/native.json 与截图是修正后的证据，上级 V2-5 原汇总保留为修正前历史。

验证覆盖人物、窗边、设置三种状态的多种窗口尺寸和实际最大化；检查全幅视口、等比缩放、时钟和菜单命中、四边无整条黑边、运镜中缩窗不重置进度、环境时间连续、同一 Core 与正常退出。精确通过数量和实际测试尺寸见 acceptance.json；独立测试只使用隔离 Validation 资料，不启动真实声音模型。
