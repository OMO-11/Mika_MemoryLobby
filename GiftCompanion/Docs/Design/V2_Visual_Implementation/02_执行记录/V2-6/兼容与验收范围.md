# V2 兼容与验收范围

2026-11-03，Asia/Shanghai。本地 Windows x64 候选；Unity 6000.3.7f1、D3D11、Built-in、Gamma、Mono。沿用数据库 v10、备份 v1、既有中文交流/日语朗读与音色；不升级依赖，不开放桌宠。

本机为 Windows 11、Ryzen 7 8845H、约 16 GB 内存、RTX 4060 Laptop GPU；当前显示器 2560×1440，工作区 2560×1368，系统缩放 150%。完整硬件快照在工程本阶段 hardware.json。没有修改系统 DPI、显示器分辨率或其他应用。

原生窗口的可用客户区受标题栏、任务栏和 Windows 缩放约束。已验证的实际窗口尺寸、最大化与四边检查以本阶段 Native/Resize/native.json 为准；不能将请求的尺寸直接当作实际尺寸。1920×1080、2560×1440 的完整客户区以及 100%/125% 真实系统 DPI 若未在结果中出现，即未覆盖，不把逻辑画布计算当作设备验收。既有小窗口与最大字号样例另在阅读回归中记录。

性能报告采集实际程序中人物、窗边、设置各 20 秒帧间隔，以及六次正常运镜往返；统计均值与高分位帧时，不把截图或 GIF 采帧速度当作运行帧率。这是单机短时观察，不代表其他显卡、长时间稳定性或 GPU 推理并行时的性能保证。

隔离验证包括主场景输入/字幕/音乐、历史/日记、设置/人物/空间维护、启动入口、跨进程保存、加密凭据读回、原备份恢复事务和随包声音启动/合成/退出。阅读样本与凭据测试使用显式隔离文本、WAV 和无效示例 Key，不调用真实对话 API，不读取正式私聊与真实 Key；真实 API 连通性与个人听感留待玩家体验。随包语音验收仅在成功结果存在时计入。

准确通过项、失败项、未覆盖项及对应新构建指纹保存在本阶段 acceptance.json。完整封装包含沿用 V1 的语音 Runtime；文件复制逐项 SHA256 校验，不把仅有文件尺寸的检查写成完整哈希复验。V1 收尾版和冻结视觉基准保留。

本轮实际尺寸确认：1280x720（1280×720）、1920x1080（1920×1080）、960x540（960×540）、1440x648（1440×648）、1100x800（1100×800）、2560x1440无边框（2560×1440）、最大化（2560×1334）。这些原生窗口检查均通过，真实系统缩放为 150%；不代表 100%/125% 已验。

本轮随包声音：日语冷启动约 91.3 秒、中文切换启动约 31.2 秒，测试短句合成分别约 13.5/13.2 秒。耗时受模型、机器负载和缓存影响，仅为本次样本；没有更换模型或宣称优化了推理速度。
