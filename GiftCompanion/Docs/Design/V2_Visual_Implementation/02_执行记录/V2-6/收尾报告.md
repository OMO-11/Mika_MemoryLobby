## 新验证与证据

逻辑与场景回归重新运行；独立检查全部面向此次完整候选，而不是复用旧切片的通过记录。

- Entry：直达陪伴空间、默认桌宠关闭、维护可达、同一 Core 与正常退出。
- Maintenance：三组设置、人物卡、空间与音乐导入、未保存确认、准确记忆移除、备份预览和安全维护子页。
- Reading：中文草稿、可见分段字幕、实际曲名/暂停、缓存复听、手动日记生成/取消、离页取消、位置/批注和来源失效。
- Resize：实际窗口尺寸、铺满、均匀缩放、时钟/菜单命中、内页可达、运镜中缩窗及四边像素检查；包含 1920×1080 窗口与 2560×1440 无边框显示。
- Window：本候选重新录制人物↔窗边往返和 10 秒终点停留，核对环境继续推进；录制帧间隔不作为运行帧率。
- Prepare/Persist：最大字幕/日记字号、人物卡与历史跨进程重开；在隔离子目录写入、加密并读回示例凭据，不让示例 Key 被真实联网客户端加载。
- Offline/Restored：真实备份、校验、恢复前备份、挂起事务和下一进程恢复，验证配置、MD 批注、导入资料和权限清零。这两个历史后端探针只在隔离数据中临时允许 Home/旧路由，不改变产品默认入口。
- Voice：由完整候选内的 Python/模型实际生成中文与日文 WAV，逐语言启动和停止；故意无效的开发 Runtime 环境变量被发布标记忽略。只有新结果成功才计为通过，听感不由 WAV 大小推断。
- Performance：六次正常镜头往返后，人物、窗边、设置各 20 秒实际帧间隔采样，记录平均 FPS、p95/p99 和进程内存。统计在 Native/Performance/Performance.json，不能推断全天稳定性或其他硬件性能。
