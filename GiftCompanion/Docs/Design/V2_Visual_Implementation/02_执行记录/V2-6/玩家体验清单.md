# V2 玩家体验清单

自动检查通过后，最后仍需要你按日常习惯体验。无需重复测试工程脚本，先做以下几件事即可。

1. 打开完整候选前，先从现有程序备份资料；关闭旧版本，再启动新候选的 EXE。
2. 输入几句中文，试一下输入法选词、换行、Esc 保留草稿，以及新一句打断上一句。听日语声音和字幕是否符合预期；准备模型期间可以先文字交流。
3. 来回进入窗边、人物、记录、日记和设置；观察纱帘/星空是否连续，最大化和恢复窗口后是否舒适、点击是否准确。
4. 试听一首已有歌曲，试暂停/继续、静音与音量，再查看音乐文件管理。双星/瑞士卷只改变装饰。
5. 在设置中改一个字号但不保存，返回时选继续编辑，再试放弃修改；确认预览能撤回。保存一个喜欢的阅读设置后重开确认。
6. 查看旧历史与日记，复听一条已有完整缓存，试继续阅读和打开 MD。只有想重新整理时才点击“回望至今”。

反馈时描述“在哪个页面、做了什么、原本期待什么、实际发生什么”，附截图即可。声音听感、动态强度、字号/布局偏好与实际 Key 联网体验由你最终确认。测试不用删除真实记忆、清理真实缓存或执行恢复；这些有明确后果的路径已在隔离资料中检查。
