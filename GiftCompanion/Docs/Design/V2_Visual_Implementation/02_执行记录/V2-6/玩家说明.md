# Mika V2 使用说明

请保留整个 `Gift-V2-Candidate` 文件夹，双击 `GiftCompanion.exe`。不要只复制 EXE。本目录包含本地语音环境，日常运行不需要 Unity 编辑器或工程目录。启动直接进入陪伴空间，桌宠入口保持关闭。

## 日常陪伴

- Enter 打开输入；Enter 发送，Shift+Enter 换行。中文输入法选词期间先完成选词。Esc 收起时保留尚未发送的草稿。
- 点击可见时钟或按 Esc 前往窗边；菜单可打开聊天记录、日记、陪伴空间、人物设定和设置。“回到未花”返回人物。细纱、星空和流星在窗边及内页继续播放。
- 窗口可以放大或最大化。场景等比铺满，多余边缘会少量裁切；文字和表单单独完整适配。菜单/时钟受人物前景遮挡，Esc 可作为备用入口。
- 左上显示当前曲名。鼠标靠近或键盘聚焦可展开音乐控制；主场景 Tab 可聚焦控制。双星和瑞士卷只切换装饰。
- 字幕跟随实际朗读分段；声音尚未准备好时仍可文字交流。“先看文字”停止当前声音并继续阅读这次回复。默认日语朗读；日语转换需要联网。

## 窗边内页

聊天记录可翻页和复听已有完整缓存；“无缓存”不能重新合成旧记录。日记只在主动点击“回望至今”时整理保留对话，支持继续阅读、旧篇和打开 MD；手工批注保留，来源更正或遗忘后旧派生正文会收起。

设置有声音、画面与阅读、资料三组。音量和画面调整可以先预览，点击保存才保留；恢复默认先进入草稿，取回可回到已保存值。未保存就离页会询问是否放弃。内容较长时使用滚轮或细滚动条，Tab/Shift+Tab 可移动焦点。

人物设定编辑已有名字、性格/说话方式、称呼/关系基调。取回文件版本会询问是否覆盖草稿；上一版与原件在资料检查中处理。陪伴空间可添加资源包、选择和打开清单；无效导入保留原空间。

## 联网、资料与维护

第一次使用联网对话时，从设置 → 资料 → 连接设置输入自己的 DeepSeek API Key。Key 只在本机 Windows 用户下加密保存；保存和测试连接是两个不同操作，测试连接才发起一次短请求。换电脑或 Windows 账户后需要重新输入。

设置 → 资料可进入音乐文件管理、记住的内容、资料文件夹、备份与恢复、资料检查和应用维护。移出歌曲不移动原音频；移除记忆不删除原始聊天；清理语音缓存后旧语音可能不能复听。操作前会说明具体对象或后果。

备份先校验并预览，确认恢复后先留当前恢复点，再重启应用。恢复会回到备份时刻，包含当时的遗忘状态，请阅读预览。Key 和安装环境不随资料备份迁移。关闭时使用设置中的退出或窗口关闭按钮，让保存和自有语音进程收尾完成。

正常玩家资料在 `%LOCALAPPDATA%\GiftCompanion`。V1 与 V2 读取同一套兼容资料；首次体验前建议做一次完整备份，避免同时启动两个版本。
