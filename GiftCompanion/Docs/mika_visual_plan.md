## 当前确定的方向

- 人物陪伴区与窗边功能区通过连续运镜连接；点击后方时间，经过人物到达窗边，菜单可返回。
- 终点正面、整体退后并上抬，显示更多上方夜空和星星，保留窗框、窗台、月光、纱帘和花瓶。
- 左下紧凑萝莉体菜单，右上24小时HH : mm与日期；文字固定场景位置，全程不淡出，仅自然遮挡。
- 左上背景音乐中枢显示当前曲名，透明平铺按钮靠近显示，双星/瑞士卷切换；无封面、歌单或独立音乐页。
- 白色细描边无框字幕；不恢复厚对话框与姓名条。输入方式的后续设计需单独确认，后端能力保留。

主画面效果依据CameraMotionV7。完整音乐中枢、对白业务、纸页展开页等没有全部并入运镜原型；报告明确区分设计规则、原型覆盖与生产集成。不要因简化演示而认为原型里的单星和曲名就替代了完整音乐中枢。
