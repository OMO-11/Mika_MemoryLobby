# Mika视觉稿第四版

2026-10-30，Asia/Shanghai。按本轮大型数字参考及墙面位置标注继续修订，仍为独立视觉稿。

[打开第四版可点击稿](Design/MikaVisual/revision4.html)。前三版与截图保留对照，未修改Unity程序、玩家资料或封存候选。

- **时间**：取消第三版的细衬线数字，改成粗重、窄长的大型方块数字；基准字高440，文字投影宽650，沿窗面倾斜铺开。文字裁切在天空与窗户范围内，头部和头饰继续遮挡，画面边缘允许裁去部分数字。保留轻微柔焦及浅紫白色明暗，避免退回角落小钟的效果。
- **菜单**：字号25→34，图标24→28，入口区域176×60→206×72。整体向左、向下移入标注的墙纸区域，让文字避开银色窗框。常态不透明度约65%→22%，靠近后仍亮为暖白色，无包围底板。
- **其余**：透明平铺音乐按钮、标准重叠五角星、瑞士卷切换、无框字幕与展开后的功能目录沿用上一版。修正入口页不应显示场景时钟与音乐叠层的样式问题。

查看“01 陪伴”可对比暗色菜单常态；鼠标移到墙面上的“菜单”可真实查看高亮并点击。“04 菜单靠近”固定展示高亮，仅供审阅。

本原型使用本机已有Impact字体展示方块数字，没有下载、复制或打包新字体；实际Unity实现时需选定等效的可发布数字字形。天空景深、窗面裁切和头部轮廓仍是静态视觉示意，不代表已实现跟随Spine动画的遮挡。

本机隐藏Edge检查20项通过，结果见 `Design/MikaVisual/revision4_checks.json`，脚本为 `check_revision4.mjs`。包含音乐显隐/切歌/暂停/音量、图标切换、菜单靠近高亮/离开变暗/点击展开、键盘访问、入口页叠层与小窗口宽度。原型不播放真实音频、不联网、不写玩家配置。
