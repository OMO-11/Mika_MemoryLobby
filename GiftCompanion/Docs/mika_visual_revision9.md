# Mika视觉稿第九版：向上拉长到红线

2026-10-31，Asia/Shanghai。独立视觉原型，正式Unity界面未改。

[可点击稿](Design/MikaVisual/revision9.html) · [正常画面](Design/MikaVisual/r9-idle.png) · [无遮挡校准](Design/MikaVisual/r9-windowcheck.png)

根据玩家标注的红线上移数字顶部。以第八版底边为锚，沿字形局部竖轴增加58像素，目标高度229.393→287.393像素（约25.28%）；顶部屏幕坐标位移约右26.17、上51.76像素。宽383.501像素、倾角26.8166°及底边两端保持，四位2106仍共用一个二维矩阵，上下等宽、四角90°，没有分段透视或6的独立倾斜。红线为手绘弧线，采用统一直线字顶贴近标注位置，不将单个字弯曲以追随曲线。

独立布局window_clock_layout_v9.json记录近似红线端点与固定底边参数。继续使用SVG自身getBBox测等宽数字的实际横向范围，Canvas测字高/基线。复用Unity实测场景及前景，未重绘素材。

窗口裁切改为真实测得的窗面；此前20像素内缩虚线仍作为校准参考，没有移动。目标文字排版矩形空白角落距真实窗沿至少2.73像素；实际可见字形不同于排版矩形，未裁切像素验证仍全部落在原20像素内缩区域。不可将排版矩形净距误报成实际墨迹净距。

浏览器23项通过。移除窗口裁切后验证75,774变化像素，真实窗外0、原内缩区域外0，最小墨迹净距20.3927像素。证据revision9_checks.json、clock_pixel_audit_v9.json、window_clock_ink_screen_v9.json、r9-window-ink-on/off.png。正常与无遮挡截图已人工查看，临时浏览器退出。前八版保留，主方案/日志/checkpoint同步，等待玩家审阅。
