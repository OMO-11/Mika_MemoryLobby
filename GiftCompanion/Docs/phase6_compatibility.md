# Phase6候选兼容范围

2026-10-19，V1候选的技术验证范围；玩家验收仍待反馈。原始证据见Docs/Validation/Phase6。

基线：Windows x64、Unity6000.3.7f1、Built-in/Gamma/D3D11、Mono；数据库v10，备份格式v1。GPT-SoVITS沿用原有Torch/CUDA依赖与中日模型，不要求玩家另装CUDA Toolkit。GPU、驱动与语音时延以本机验证报告为准；其他显卡和CPU推理尚未建立支持承诺。

屏幕目标为100/125/150/200%缩放、负坐标、多屏与混合DPI。Phase5已有本机原生拖动/命中验证；没有实际设备或系统设置的项目保留“未验证”，不通过改全局缩放打断玩家桌面。锁屏、睡眠、热拔显示器、新Windows账户及其他机器需要单独体验记录。

本机：Windows11专业版10.0.26200，Ryzen7 8845H/16逻辑线程，系统可见物理内存约15.3GiB，RTX4060 Laptop（驱动32.0.16.1062），另有780M与ToDesk虚拟适配器。今天实际枚举到1个2560×1440/150%屏幕；没有更改系统显示设置。

独立完整目录已移动到新的中文路径，在移除开发Key注入、故意设置无效开发Runtime覆盖的情况下，中日两套包内模型均合成并正常退出。安装树的文件名/大小/修改时间无变化，运行配置和缓存写在用户目录。此检查不等同于严格只读ACL或另一台机器测试。

日语首次预热88.365秒、短句推理10.130秒；随后中文预热23.445秒、短句推理10.281秒。这里测量的是模型启动和单次推理，不能当成完整流式对话的首音时延或所有机器的保证。首次加载较慢时，界面与文字路径仍可用；语音启动等待上限按现有配置处理。本轮未量化/升级Torch，也未删除中文模型。

本轮完成12次模式往返与600.46秒Home空闲观察，全部6项检查通过并正常保存退出。主进程CPU按16逻辑线程归一到整机容量，平均1.071%；不是整机总负载或桌宠30帧场景指标。外部Windows中间两次采样：工作集371.10→374.11MiB、私有内存564.95→566.17MiB。Unity内置Process接口返回私有内存0，该数值无效；没有完整终点内存样本，不能据此断言无泄漏。1—2小时真实使用与更长周期的缓存/显存增长仍需后续观察；短时通过不代表所有设备或全天稳定性。

语音缺模型、初始化失败或端口被其他进程占用时保留文字功能，不接管其他进程。无Key和断网不伪造回复。跨机器恢复不迁移Key和外部应用权限；旧程序拒绝高版本数据库。
