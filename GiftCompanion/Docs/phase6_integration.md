# Phase6 集成与范围冻结

2026-10-19，用户授权按Phase6顺序实施，暂缓Phase5玩家体验测试。

| 宪法要求/边界 | 当前实现与证据 | 本轮处理 |
|---|---|---|
| 唯一角色与跨模式状态 | AppRoot/CharacterCore、SQLite v10；Phase5 Edit136/Play35、Live39/NoKey30 | 保留唯一实例；维护期间阻止切换 |
| 共享历史/记忆/人物卡/日记 | 同一数据库；工具来源不进自动记忆与日记 | 备份包括一致数据库和可读MD，恢复不重放工具 |
| 陪伴声音/字幕/BGM | 中文主答→日语本地化→GPT-SoVITS；双语、缓存、单曲循环 | 保留既有调校；仅处理安装路径和生命周期 |
| 桌宠/工具权限 | 单轮允许、逐次敏感确认、13项白名单、审计 | 恢复后清空外部应用与搜索范围，重新配置 |
| 生命周期/退出 | 统一取消/保存/受控模型退出 | 增加后台记忆任务排空和维护锁 |
| Key与离线使用 | DPAPI读取已有；尚缺应用内保存 | 增加掩码输入、显式测试、保存后重启加载 |
| 资料保护 | 迁移前原生SQLite备份已有 | 增加完整快照、校验暂存、恢复点和启动事务 |
| 独立运行目录 | Phase5约305MB程序+工程共享8.66GiB语音环境 | 在隔离发布目录装配单份Runtime；源环境不改 |
| 屏幕/占用/兼容 | Phase5双屏实际命中、短时CPU/GPU测量 | 记录真实设备和新增验证；未测设备明确标注 |
| 普通玩家维护 | 文件清单与导入菜单已有 | Home统一资料/连接入口、说明与脱敏诊断 |

基线证据见`Validation/Phase5/acceptance.json`、`phase5_delivery.md`。旧验收与旧构建不覆盖；素材、CHDDD V7、源Runtime不裁剪。本轮不换模型、不引入新UI框架、不启动Phase7路线。数据库仍v10，备份格式单独版本化。

新发现的集成风险：现有EnterForeground仅发取消而未等待后台收尾；AppController未拒绝维护期间切换；Key客户端绑定启动生命周期。分别通过排空租约、维护门闩和保存后受控重启解决，避免重复角色或带着旧Key继续调用。
