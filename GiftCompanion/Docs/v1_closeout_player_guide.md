# Mika Gift · V1收尾候选

双击同目录GiftCompanion.exe，保留整个目录。现在启动会直接进入陪伴空间；桌宠入口暂时关闭，历史与共同记忆保留。

Enter打开输入并发送，Shift+Enter换行，Esc打开菜单。设置中可调整音量、字幕、声音与画面；“资料与回顾”可管理音乐、空间、人物设定和日记。默认日语朗读、中文正文；声音准备期间可以先文字聊天，等待中可点“先看文字”。

首次联网配置：Esc → 设置 → 资料备份 / 联网配置，进入“资料与连接”输入自己的DeepSeek Key，保存并重启。重启仍直接进入陪伴空间。返回Home可继续进行维护和退出，Home不再显示桌宠入口。

音乐单曲循环，手动切歌；切换空间不重置人物和记忆。日记由你主动生成，保留数据库与MD两份。资料菜单可备份/恢复，Key不进入备份，私人备份自行保管。

本次设置保存在玩家资料Config/app_entry.json。默认StartupMode为companion，PetEntryEnabled为false；维护者后续可以恢复入口，普通使用不必编辑文件。完整过程见同目录《V1设计与实现总结.md》，维护与兼容限制见配套说明。
