# 动作优化 V2

更新日期：2026-10-09，当前为 V2 修订 7。打开 `CHDDD_actions_v2.blend`；Unity 导入 `CHDDD_Actions_v2.unitypackage`，使用 `Assets/CHDDD/Unity/CHDDD_Actions_v2.prefab`。全部动作预览：`Previews/ActionsV2/index.html`；本轮优先审查 `Previews/ActionsV2/readability.html`，同步查看小尺寸、轮廓和上一轮修订 6 的 Unity 连续帧。

## 本轮修改

- Dragging 使用原始 GLB 中按 1 起算的第 29 条 `CH0069_Formation_Pickup`，完整长度 11.233 秒。保留游戏原有身体、头发、裙摆与披肩运动；将来源中危险的眼部缩放通道替换为本项目已验收的面部方案，避免露出眼眶内部。
- Thinking、Working、HeadPat、Wave、Success、Confused 和点击反馈增加身体重心、肩颈、视线与手腕的协调。挥手有抬手和收势，庆祝有蓄势与回落，疑惑有寻找和摊手，入睡有掩嘴呵欠。
- 发衣跟随由实际头部、躯干、骨盆与手臂的运动驱动，加入延迟、阻尼与收尾回落。通过原有骨骼烘焙，Unity 不需要额外物理插件。举起动画沿用原版发衣动画，避免叠加重复摆动。
- 每个动作有独立面部时间线，包含眼睑、眉形、视线、短眨眼与七个现有嘴型的变化。例如挥手“注意→微笑→眨眼→收势”，庆祝“专注→惊喜→开心→满足”，疑惑“疑问→担心→释然”。九个旧情绪模板仅作为可选手动控制，不再作为特殊动作的默认演出。
- 第二次回修调整嘴型出现时机，并把单次反馈的首尾对齐待机。七个循环和六个进入、退出片段同步处理身体与面部边界。
- 武器不显示；原有光环抬高与头部绑定、柔和增厚眉形、闭眼形变和材质保持。原始 CH0069 与 V1 交付保留。打开 V2 前的当前 Blender 场景已保存为 `CHDDD_live_before_v2_20261008.blend`。

## 动作与表情播放

V2 含 18 个身体 Clip、18 个动作专属面部骨骼 Clip、9 个可选情绪 Clip。眼睑、眉形和嘴型的完整变化另由 `action_face_profiles_v2.json` 提供；必须使用本版预制体与控制器，单独播放 FBX 身体 Clip 无法得到完整表情。

```csharp
var pet = GetComponent<CHDDDBodyControllerV2>();
pet.PlayAction("Wave");
pet.PlayAction("Dragging"); // 自动经过拿起短片，再进入原版举起循环
pet.ReturnToIdle();         // 支持放下、结束摸头、唤醒等对应退出短片
pet.SetManualEmotion("sad", .5f); // 暂时让桌宠逻辑接管情绪
pet.ResumeActionExpressions();   // 平滑恢复当前动作的表情过程
```

面部骨骼层不包含 Head，头部运动属于身体动作。运行时在 Animator 更新后同步采样眼睑、眉形和嘴型，切换中途被打断时从当前显示结果继续过渡。默认普通切换 0.28 秒。发衣动画已经烘焙，后续接入 Procedural Rig 时需避免在同一批骨骼上重复添加完整摆动。

## 暂停后继续细化：修订 3

挥手、庆祝、疑惑和点击反馈采用有快慢变化的动作时钟，身体与表情共享时序。挥手先稍作准备、较快抬手，摆腕逐渐减弱；庆祝先蓄势、再抬手开心、放松收势；疑惑的左右寻找增加停留。移除挥手叠加的重复腕部旋转和庆祝中不必要的重复点头。

发衣跟随按骨骼链逐节增加延迟：发根较稳、发梢稍晚跟上，裙摆根部幅度小、衣角缓慢回落。披肩增加同侧手臂抬起时的牵动，并修正左右与中央布料的驱动归属。原游戏 Idle、Walk、Dragging 已包含发衣运动，保留来源演出，不叠加整套额外摆动。

新增循环角速度检查发现，原先只有首尾姿态一致，待机发梢、行走及举起足边装饰仍有速度突变。现在修整边界附近四帧的切线，中段动作保持；举起的头部、骨盆与四肢主体轨迹继续沿用原第 29 条动画，只修整发衣与装饰的循环接缝。结果见 `body_v2_loop_velocity_diagnostics.json`，修复前对照见 `body_v2_loop_velocity_before_resume.json`。

上轮模型、资源包与制作脚本另存 `Checkpoints/V2_before_resume/`；恢复前的未保存 Blender 场景另存 `CHDDD_live_before_resume_20261008.blend`；上轮 GIF 保存在 `Previews/ActionsV2/BeforeResume/`，可通过预览页切换对比版本。

## 设计方向确认后：修订 4

用户选择“接近游戏原版：互动动作更活泼，手势和反应更明显”。本轮集中调整 Wave、Success、Confused、HeadClick、BodyClick 五种短反馈，不改变已验收的眉形、眼睑和嘴型资产。

- 挥手：抬手更高，前臂、肩膀和手腕共同摆动；头部有轻微反向协调，另一只手在胸前呼应，后续摆幅渐弱。表情依次为注意、明快微笑、短眨眼、放松收势。
- 庆祝：蓄势后握拳上提，另一只手收向胸前；身体先下沉再上扬，末尾带满足的点头回落。表情由专注、惊喜转为开心和满足。
- 疑惑：转头寻找更清楚，歪头摊手有另一只手的轻微呼应；视线和眉形先疑问、再略担心、最后稍微释然。
- 点击：先快速后撤或缩身，再侧头、抬手或靠向胸前回应；头部点击带略俏皮的疑问转为开心，身体点击带视线移开与略害羞的微笑。

新动作直接驱动原有分层发衣跟随，身体和表情仍共用节奏。脚部保持固定，不启用根位移。HeadClick 默认淡入 0.10 秒、BodyClick 0.12 秒、Wave 与 Success 0.18 秒，其余仍为 0.28 秒；可通过 `PlayAction(name, seconds)` 显式覆盖。身体与面部使用同一淡入时长，避免短反馈的起势被过长的淡入吞掉。

五个调整动作重新按 24 FPS 渲染；另有 35° 斜前方和 155° 斜后方共 50 张抽样图，检查手臂、头发和衣服的动态关系。姿态图见 `Previews/ActionsV2/revision4_pose_review.jpg`，侧后方图见 `Previews/ActionsV2/Revision4Sides/contact.jpg`。`body_v2_revision4_design_validation.json` 对照上版曲线与表情样本，确认其余 13 个动作及其面部过程保持一致。

本轮前的完整交付与脚本保存在 `Checkpoints/V2_revision3_before_lively/`；上一轮 GIF 在 `Previews/ActionsV2/Revision3/`，预览页默认提供这版对比。最终是否符合用户期望的活泼程度仍需审查预览；本版不以自动检查声称达到官方同等制作水准。

## 小尺寸身体语言重制：修订 5（2026-10-09）

本轮按用户的新要求，以清楚的情绪意图、关键姿态和停留节奏重做五种反馈；日常动作保持低强度，不把全身动作统一放大。动作元数据记录 `daily`、`emotion`、`special` 三层及推荐触发方式。频率限制尚需正式桌宠调度接入，资源包本身不会主动安排特殊演出。

| 动作 | 时长 | 身体语言与节奏 | 层级 |
| --- | --- | --- | --- |
| Confused | 3.4 秒 | 先停下和后缩，手靠脸颊、歪头约 23°，保持约 0.61 秒，再缓慢恢复 | 情绪响应 |
| Success | 3.4 秒 | 收手下沉蓄势，双拳上提、双脚踮起，保持喜悦约 0.61 秒，落回并缓冲放松 | 情绪响应，中高强度 |
| Wave | 3.6 秒 | 收身准备，探身展示问候姿态，单手开放地招手两次，柔和收势 | 低频特殊演出 |
| HeadClick | 1.8 秒 | 双肩和双手受惊、身体后撤，短暂停顿，再歪头认出用户并放松回应 | 突然点击的特殊演出 |
| BodyClick | 2.6 秒 | 收肩蜷身、双手近胸、脚尖内扣，保持约 0.52 秒，视线移开后短暂回望，再恢复 | 情绪响应 |

脚部不再全部强制固定同一姿态。踮脚与脚尖内扣采用足尖支点，检查整个动作的接触点误差在 1 毫米以内；这是局部骨骼动作，不启用根位移。庆祝没有离地跳跃，适合作为中高强度回应。眼睑、眉形、嘴型材质与九种已验收情绪资产保持，眼部不使用缩放表达惊讶。

发衣跟随重新调整逐节延迟和阻尼；长发在歪头保持时逐渐向重力方向回落，披肩随同侧肩臂牵动，裙摆随重心变化后延迟缓冲。日常思考、工作、摸头、打盹以及进入退出片段也重新烘焙发衣过程；源 Idle、Walk 和原动画 29 的身体曲线保持。其余 13 个面部过程与修订 4 对照一致。

本轮循环回修记录：先建立全身关键姿态，再修正受惊停留与长发下垂；随后检查 160 像素画面和纯轮廓，发现庆祝与挥手都采用单手上举、轮廓过于相似，因此将庆祝改为双拳上提、受惊改为双手张开后撤，再重新导出与检查。首轮小尺寸图保存在 `Previews/ActionsV2/V5_pass1/`。

审查页支持 160 / 240 像素画布、彩色与轮廓同步、暂停和逐帧、修订 4 对比。全部动作按 24 FPS 连续渲染，五种重点反馈另在 Unity 实际渲染连续帧。另检查 35° 斜前方和 155° 斜后方的关键姿态。实际桌宠窗口的显示倍率与系统 DPI 仍需接入后复核；画布尺寸含光环，角色本体稍小。

数值结果：`body_v2_revision5_readability_validation.json`（关键姿态停留、足尖接触、实际蒙皮网格位移、来源曲线保留）、`body_v2_revision5_small_preview_validation.json`、`body_v2_revision5_unity_frames.json`、现有 Blender / Unity / 循环速度 / 交付依赖验证。发衣测试比较同一身体姿态下正常发衣骨骼与固定发衣骨骼的实际网格差异，替代仅统计变化骨骼数量；该检查不等同于可见性、穿插或艺术质量的自动认证。

## 已验收姿态的衔接回修：修订 6（2026-10-09）

用户已审查通过 Confused、Success 与两种 Click 的整体动作。本轮保留这些动作的关键姿态、出现时刻、总时长、可读停留和全部 18 条面部时间线，调整各子动作间的运动连续性。Wave 及其余身体片段保持原曲线。

旧版在每个中间控制点都把速度归零，造成多段起停。本轮以有界五次曲线连接：经过中间姿态时保留连续速度；真实停留及方向反转仍允许减速。各控制值不超过原关键姿态范围，接缝的速度与加速度连续。重心略先行，头部与手部随后，减少同时起落；单次动作不再重复叠加整段首尾缓动。发衣继续由身体实际运动驱动，收势延迟回落。

- Confused：后缩到歪头的头部运动继续通过过渡点；恢复时手臂与头部逐渐松开，去掉收势中段的多余刹停。
- Success：保留蓄势、踮脚双拳和落回缓冲，手臂经过蓄势与回落中的过渡姿态时连续运行，随后逐步放松。
- HeadClick：保留受惊的短停与认出用户的回应姿态，错开身体缓和、头部转向和手臂落下；连续检查发现的局部手腕急翻另行修正。
- BodyClick：后缩接收肩近胸，回望接松手回正，经过中间姿态时连续过渡。

连续检查还发现原 IK 路径在手臂接近伸直时会让肘部出现速度尖峰，因此将上臂、前臂和手腕作为整条链回修：使用已验收阶段的世界空间朝向作为约束，连续插值后按父子顺序转换回局部旋转，避开 IK 极点与手指方向归一化混合造成的转向尖峰。关键手势继续与修订 5 对照检查。

本轮同条件对比以 Unity 6000.3.7f1 实际连续渲染为准，新旧帧均按 24 FPS、相同相机与时长采样。查看 `Previews/ActionsV2/readability.html`，可正常、半速、四分之一速度播放，暂停、逐帧和拖动进度。旧帧在 `Previews/ActionsV2/Revision5/UnityMotion/`，旧 GIF 在 `Revision5/`。

验证记录：`body_v2_revision6_flow_validation.json` 对照已验收阶段、控制曲线连续性、其余动画曲线与全部表情时间线；`body_v2_revision6_motion_diagnostics.json` 记录实际世界空间骨骼速度和加速度；`body_v2_revision6_readability_validation.json` 复核停留、脚部接触和发衣蒙皮运动。Blender、Unity、完整预览和包依赖检查沿用通用报告路径。数值检查证明约束保持与局部问题修复，流畅观感仍由人工连续播放审查。

修订 5 完整模型、Unity 资源与制作脚本备份在 `Checkpoints/V2_revision5_before_flow/`；其中 `live_scene.blend` 保留修改前未保存的 Blender 现场。本轮资源继续使用 V2 文件名，映射版本为 `revision: 6`，尚未接入 GiftCompanion 正式运行场景。


## 手势、翅膀与表情局部回修：修订 7（2026-10-09）

根据用户逐项反馈制作，沿用修订 6 的连续衔接方法和所有动作时长。

| 动作 | 本轮局部变化 |
| --- | --- |
| Confused | 手移至头侧，掌心朝向自己，手指轻弯；在原有歪头停留中轻挠两次，再连续收手。头部、躯干和下肢沿用原来的幅度。 |
| Success（用户所称 succeed） | 双手向头部上缘举高，肩部协调上抬；保持原有挺胸、重心与踮脚幅度。举起后闭眼并抬眉，随后恢复睁眼。披肩侧片随抬臂局部打开、向外让位，再随落臂收回。 |
| Wave | 挥手期间双翼轻扇，翼根先动、外侧羽片稍后；最后一挥直接接上收手，经过原收势中间姿态时保持速度。 |
| HeadClick | 保留原身体动作；受惊阶段闭眼、使用现有图集的三角嘴，形成 -A-。缓和及认出用户时改为皱眉、抿嘴佯装生气，整个过程不使用笑嘴。 |
| BodyClick | 身体动作保留，尾段双翼短暂轻抖并逐渐收稳。 |

现有 `Character_Mouth.png` 中的单元 200 是三角张嘴，本轮加入动作表情的第八个槽位；未绘制新贴图，原七个单元与九种已验收情绪定义不变。Blender 节点和 Unity 动作表情控制器同步支持八槽，并验证原七槽配置兼容。必须使用本轮完整 Unity 包中的控制器与表情配置，单独替换 FBX 不能实现完整表情。
