# CHDDD 第一版动作交付与进度

更新：2026-10-08。Unity 6000.3.7f1 独立测试工程验证通过，第一版资源包与全部动作预览已生成，等待人工动作审查。

## 已保存

- `CHDDD_actions_v1.blend`：18 个身体动作（7 个循环、5 个单次反馈、6 个进入／退出），日常无武器；已抬高光环 0.065 个模型单位，仍跟随头部。
- `Unity/CHDDD_Actions_v1.fbx`：包含 18 个身体 Clip 和 9 个配套面部 Clip，已通过 Unity 导入验证。
- `CHDDD_Actions_v1.unitypackage`：本版完整资源包。导入后使用 `Assets/CHDDD/Unity/CHDDD_Actions_v1.prefab`。
- `Unity/AnimationsV1/`：运行时使用的独立动画，已分离身体与面部通道。
- `Unity/body_action_map_v1.json`：动作、循环、时长、进入／退出和衔接映射。
- `Unity/expression_map_v1.json`：配套面部动作映射；已验收的原表情与形变数据保持原样。
- `CHDDD_BodyControls_v1.py`：Blender 身体动作预览侧栏，已嵌入动作 Blend；重新打开后可在 Text Editor 中运行。
- `Previews/ActionsV1/index.html`：可切换查看全部 18 个动作的约 12 FPS GIF 预览；同目录保留渲染帧和抽样图。单次动作在预览页重复播放便于观察，Unity 内仍为非循环。
- `body_v1_blender_validation.json`：Blender 姿态端点、循环角速度与位置速度抽样、衔接、站立脚底稳定、面部通道分离及数据保留检查通过。该检查不是最终艺术质量验收。
- `CHDDD_before_actions_v1.blend` 与 `character_manifest_before_actions_v1.json`：制作前备份；原恢复文件 `CHDDD.blend` 保持原样。

## Unity 验证与使用

2026-10-07 因 Unity 环境错误暂停；2026-10-08 用户恢复环境后完成测试与打包。已有 `CHDDD.unitypackage` 是之前的表情恢复版本；本版请使用 `CHDDD_Actions_v1.unitypackage`。

`body_v1_unity_validation.json` 验证通过：Generic Avatar、18+9 动作、循环配置、多轮循环、全部单次／进入／退出自动衔接、播放接口、眼眉渐变不被身体动画覆盖、身体头部姿态保留、光环绑定、武器网格缺席、根位移禁用及 Shader 错误检查。

```csharp
var body = pet.GetComponent<CHDDDBodyControllerV1>();
body.PlayAction("Thinking");
body.PlayAction("HeadPat"); // 自动先播放进入短片，再进入循环
body.ReturnToIdle();        // 有退出短片时先退出，否则过渡回 Idle

var face = pet.GetComponent<CHDDDExpressionController>();
body.followSuggestedEmotion = false;
face.SetEmotion("happy", 0.5f); // 可独立搭配身体动作
```

单次反馈完成后自动回 Idle；进入短片自动衔接对应循环，退出短片自动回 Idle。动作与实际 Clip 由 `body_action_map_v1.json` 映射。

材质适用于 **Built-in Render Pipeline**，本次未转换 URP Shader。Unity 验证使用独立工程与无图形批处理，不等同于正式桌宠窗口的最终画面、性能或交互验收。GiftCompanion 正式运行时尚未接入本版动作，也未修改其编辑器版本。

## 后续接续

下一步根据人工动作反馈完善姿态、幅度与节奏，再接入正式桌宠场景。窗口移动、Head/Body 触摸识别、拖动高于摸头的交互优先级、工具任务事件与 LookAt 仍由桌宠宿主接入。

身体负责 Head／Neck，新的面部动画副本仅负责眼、眉与嘴；不要用旧的含 Head 蒙版直接覆盖本版低头动作。
