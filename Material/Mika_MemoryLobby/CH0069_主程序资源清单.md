Thinking、Speaking 是运行时组合，**不是名为 Thinking／Speaking 的独立 Spine 动画**。启动时加载器先在轨道 0 单次播放 `Start_Idle_01`，再自动衔接循环 `Idle_01`；不要在每帧重新启动它，也不要用整段原作 Talk 动画代替任意 TTS 口型。

摸头复用 `Pat_01_M` 与 `PatEnd_01_M`。前者为零时长姿态，需要由手势控制保持，不能等待 Complete 结束，也不是循环摇头片段；后者约 0.333 秒退场。命中沿 `Face`、`Ball_Hair_01`、`F_Hair_01`、`F_Hair_02` 的当前网格，不包含身体、光环或长发。

## 6. 主程序接入所需环境与步骤

当前本地组合：Unity **6000.3.7f1**、spine-unity 包声明 **4.2.120**、spine-csharp 包声明 **4.2.37**、URP **17.3.0**、Input System **1.18.0**、UGUI **2.0.0**。运行库与 Shader 位于 [MemoryLobby/Assets/Spine/](W:/Machine/VSCode/Mika_Gift/Material/Mika_MemoryLobby/MemoryLobby/Assets/Spine)；若目标工程尚无对应运行库，需要一并带入。这里列的是本地实际组合，不把不同语言运行库的补丁版本号互相套用。

1. 将 JSON 中 `required=true` 的文件及对应 .meta 按 `targetProjectPath` 放入主工程；保留父目录的 .meta，复制整个相关子目录最稳妥。可选加入参考场景与两段语音。排除 Library、Temp、Editor 验证工具、额外表情 PNG。
2. 用现有 Bootstrap 作为加载和绑定入口：赋值 `profile`、`renderCamera`，将 `enableLocalBehavior` 设为 true；它在 Start 自动 Initialize。完整复制时直接打开参考场景即可复现，无需另做 Spine 工程。
3. 若主程序已有自己的加载器，按 Bootstrap 的原顺序创建骨架与循环 Idle，再绑定 Motion、Expression、Pointer 和 Speech；随后按 PlayIntro 的队列与交互禁用逻辑启动入场。保留唯一嘴部写入者。关闭 Bootstrap 的 F8 验证 UI，让主程序状态入口驱动组件。
4. 保持 `Spine/Skeleton` Shader、`_StraightAlphaInput=1` 和 `_STRAIGHT_ALPHA_INPUT`；原始 PNG 按 sRGB、无 mipmap、Bilinear／Clamp 加载，骨架 scale=0.01。参考正交相机为位置 (0, 9.7, -100)、orthographicSize=9.5。改变构图后重新检查头部命中与鼠标坐标。
5. 把对话状态转为上述 Idle／Thinking／Speaking 入口，并传入真实语音。验证用 `Speech.Stop()` 会把 Speaking 切回 Idle，主程序需按当时业务状态重算表现；摸头结束不得终止仍在进行的对话。
6. 场景切换、UI 接管、失焦和取消时清理输入捕获、触摸与旧音频；新的主程序场景仍需做一次播放和输入验收。
