# Mika Gift · V1 完善候选

双击GiftCompanion.exe，保留整个目录。无需安装Unity或Python；换位置时一并移动Runtime和其余文件。硬件范围与已知限制见兼容范围.md。

首次使用在“资料与连接”配置自己的DeepSeek Key，保存后重启。没有Key时仍可看场景和已有资料。日语为默认声音，回复正文和字幕保持中文；首次准备声音可能较久，可以先文字聊天。语音回复等待中点击“先看文字”，本轮停止朗读并显示已收到的中文，下一轮仍按声音偏好回复。

陪伴空间按Enter输入，Shift+Enter换行，Esc收起或打开菜单。菜单的“资料与回顾”可以添加背景音乐、切换陪伴空间、修改人物设定、查看相处日记。背景音乐默认单曲循环，仅手动切歌切换；切换空间不重置人物与共同记忆。

“设置 → 画面与阅读”可调整亮度、高光柔和程度及日记字号、行距。拖动是预览，点击保存才保留；直接返回会恢复已保存画面。“预览原版画面”可以对照调整前的画面参数。字幕字号在设置首页单独保存。

日记由你主动生成，回望从相识到现在的已保留聊天，以自然段展示；同一陪伴场景会话中重新打开或切回同一篇可继续阅读。数据库与Diary文件夹的Markdown分别保留；手工批注不会被普通打开操作覆盖，编辑MD不会自动改写角色记忆。

“资料与连接 → 资料检查”可选择中文名称对应的配置。重置需再次确认；切换项目或离开页面会取消确认。人物设定、背景音乐和陪伴空间还可恢复上一版，当前原件另存到ConfigRecovery。聊天和共同记忆不会因此清空。

“备份与恢复”可以导出完整资料快照，选择是否包含历史语音；恢复先预览时间、范围和空间需求，再由你确认。Backups是恢复前压缩备份，RestorePoints是原资料副本，ConfigRecovery是单项配置原件。它们可能包含早期私人内容，请妥善保管；程序不会自动清理。Key不进入备份，换Windows账户需要重新配置。

这是供玩家测试的候选版。旧V1可保留用于回退，回退前核对资料版本，详见维护说明.md。桌宠继续使用同一人物与记忆，默认正常聊天，桌面操作按单轮授权，桌宠不加载语音模型。
