# Phase 4 交付与测试说明

2026-10-17。**正式中文语音链与发布技术验收完成，交玩家测试反馈。** 当前结论见 [phase4_status.md](<phase4_status.md>)，完整证据见 Validation/Phase4/acceptance.json；主观听感不由自动测试代替。

## 启动

资源管理器双击工程 `Tools/Start-Phase4.cmd`，或运行 `Tools/Start-Phase4.ps1`。独立程序位于 `Builds/Phase4/`。该启动器沿用已配置的本机 DeepSeek Key，只传给应用子进程，并定位现有 `Runtime/GPT-SoVITS`，不用再安装 Python、解压模型或复制第二份约 8.66 GiB Runtime。模型子进程不继承该 DeepSeek Key。

正式资料仍在原用户资料目录；新版本首次使用会以原生备份方式升级 memory.db 到 schema v9，新增音频索引，原文 / 人物卡 / 记忆 / 日记保留。旧 Phase3Plus / Phase3 构建与证据仍在，但不能读取升级后的同一库；本轮测试全部使用独立 Validation 数据，未运行正式聊天库。

## 本轮可以测试的行为

| 操作 | 预期 |
| --- | --- |
| 进入陪伴空间 | 自动准备中文语音；准备期间的本轮先显示文字，就绪后的新回复使用语音 |
| 发送消息 | 按正文完整语义分句，首段就绪即可播放，不等待全文；字幕跟随正在播放的段落 |
| 发声 / 停顿 / 结束 | 已适配大厅按真实 PCM 张嘴；BGM 平滑压低再恢复，不解除静音、不自动切歌 |
| 再发消息 | 立即停止旧声音，丢弃旧轮迟到音频；实际推理仍保持单并发 |
| Esc → 设置 → 声音与复听 | 开关 / 音量保存、重试语音、停止回复 / 复听、查看占用、清理缓存、阅读独立说明 |
| Esc → MomoTalk | 有完整缓存的回复可复听；无 Key / 无模型服务也可读取，实时对话优先 |
| 缓存被删除 / 清理 | 显示“无缓存”，不自动重新合成；聊天 / 共同记忆 / 人物卡 / 日记保留 |
| 语音故障 / 离开空间 | 保留文字能力；正常离开 / 退出停止自有服务和队列，不停止其他监听程序 |

初次加载模型、首句合成与后续句子都有实际延迟，短回复可能在声音开始前已经完成全文。程序按首段就绪播放，不通过拖慢文本制造重叠；实际耗时见发布报告。控制流测试单独验证“首段播放不受全文完成门槛阻塞”。当前没有接入麦克风或语音识别，输入仍用文字。

## 文件与维护

现有音乐、空间、人物卡、日记文件继续使用。新增：

- `Config/voice_runtime.json`：独立运行时 / 语音配置引用、超时、断句 / 队列边界、BGM 压低参数。
- `Config/settings.json`：新增 VoiceEnabled / VoiceVolume，仍由菜单保存普通设置。
- `AudioCache/<随机会话ID>/<片段序号>.wav`：实际可读取音频；schema v9 audio_records 保存消息关联 / 顺序 / 时长 / 配置指纹。
- `声音与复听.md`：新玩家说明，不覆盖原有手写《使用说明.md》。声音面板可直接打开。
- `Logs/voice-process.json`、`voice-host-status.json` 和 app 日志：自有服务身份 / 安全错误类型与计时；不记录 TTS 正文或实例校验标识。

资料维护报告纳入语音状态与配置指纹。配置错误保留原文件并回退文字，启动 / 退出由应用管理。接口细节见 [player_content_contracts.md](<../../02_设计与实现/player_content_contracts.md>)；独立模型装配历史见 [voice_runtime.md](<../../02_设计与实现/voice_runtime.md>)。

## 验证与体验边界

最终逻辑回归为 Final2 EditMode **78/78**、Final3 PlayMode **19/19**。包含旧版库迁移备份、无效解释器 / 外来端口、正文断句 / WAV 校验、完整缓存 / 孤立文件、无合成器复听、音量恢复，以及正式 Companion “文字已提交仍可继续朗读 / 新消息立即停声 / 未就绪先文字”场景。

最终 Windows Release / Mono / D3D11 构建零错误，301,676,459字节。最终四模式 **Write / Restore / NoKey / Faults 全通过**，覆盖真实语音 / DeepSeek、取消 / 缓存 / 离线复听、缺失文件与服务、自有进程崩溃 / 菜单重试、外来端口、缩放、启动中离开及重入 / 退出。此前首版证据保留 FirstPublished，不与最终报告混用。

最后Core测试后仅修订Runtime符号回复显示 / 坏缓存提示及PlayMode用例，Core78项保持对应。最终本机模型加载约21.104秒，短回复文字约1.637秒完成、首音约5.910秒；该短回复未观测生成 / 播放重叠，如实保留actualOverlapObserved=0。已查看最终自有客户区画面，未用截图冒充声音听感验收。

请重点反馈声音是否接近预期、口吻与语气、音量、句间停顿、字幕节奏、打断与菜单操作。默认中文；日文模型 / 配置保留，本轮不宣称完成日文整链听感验收。其他显卡 / CPU 尚无整链验收，当前开发启动器沿用本机运行时；跨机安装与进一步精简留在 Phase6。

通用 Spine 空间仍支持语音 / 字幕，未提供嘴部映射时保持基础表现，不虚构口型能力。第二份新空间待正式资源交接后单独适配。日记仍待玩家体验；Phase5 工具和 UI 整体美化未提前展开。
