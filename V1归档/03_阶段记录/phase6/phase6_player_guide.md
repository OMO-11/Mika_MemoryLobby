# Mika Gift · V1候选

双击同目录的GiftCompanion.exe。请保留整个目录，移动程序时一并移动Runtime与其余文件。程序与训练素材分开，普通玩家无需安装Unity、Python、Blender或Git。显卡仍需合适驱动，实际支持范围见“兼容范围.md”。

首次启动可在“资料与连接”输入自己的DeepSeek API Key，保存后重启；也可以稍后再填。当前Key只在本Windows账户加密保存。选择“陪伴空间”进入记忆大厅，或“来到桌面”切换成桌宠。两种形态使用同一角色、对话与记忆。默认日语朗读，主回复和字幕保留中文；没有Key时可查看场景与已有资料。

陪伴空间菜单中可以编辑人物卡、导入音乐、切换空间、查看MomoTalk和生成相处日记。BGM默认单曲循环，手动切歌才切换。桌宠默认流式聊天，按需为单轮开启“允许桌面操作”；敏感操作仍会再次确认。桌宠不加载语音模型。

Home的“资料与连接”负责Key、备份恢复、重新读取配置和脱敏诊断；各模式设置也能进入。首次体验后建议先做一份资料备份。详见“资料备份与迁移.md”。

安装目录当前需约10GiB空闲容量（以Release/release_manifest.json的实际字节数为准），另为玩家资料、历史语音及备份预留空间。资料位于Windows本地应用资料目录的GiftCompanion，通过菜单即可打开；安装目录移动不会自动迁移这些资料。请放到普通可读目录，避免极深路径。首次模型预热会比缓存复听慢，缺少语音依赖时保留文字功能。

这是候选版本，技术验证和玩家体验分别记录。未验证硬件、长时间体验及仍待反馈的事项见“兼容范围.md”。
